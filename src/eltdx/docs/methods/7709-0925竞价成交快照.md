# 7709-0925正式撮合

## 作用

当日和历史 09:25 正式撮合已经拆成两个入口：`client.trades.opening_match_today(code)` 和 `client.trades.opening_match_history(code, date)`。两者从成交明细中筛选正式撮合，`status=8` 的竞价过程快照不会被当作正式成交。

| 项目 | 内容 |
| --- | --- |
| 当日调用 | `client.trades.opening_match_today(code)` |
| 历史调用 | `client.trades.opening_match_history(code, date)` |
| 数据来源 | 当日 [`0x0fc5`](../COMMANDS_7709.md#cmd-0x0fc5)，历史 [`0x0fc6`](../COMMANDS_7709.md#cmd-0x0fc6) |
| 返回模型 | `TradeTick | None` |

接口会自动完整分页，并只选择 `time_minutes == 09:25` 且 `event_kind == "opening_match"` 的记录；没有找到时返回 `None`。

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    today = client.trades.opening_match_today("sz000001")
    result = client.trades.opening_match_history("sz000001", "2026-05-20")

for opening in (today, result):
    if opening is not None:
        print(opening.time_label, opening.price, opening.volume, opening.trade_amount_yuan)
```

## 解析字段

| `TradeTick` 字段 | 含义 |
| --- | --- |
| `full_code` | 完整代码 |
| `time_label` | 成交时间，接口只返回 `09:25` 正式撮合 |
| `price` / `price_milli` | 竞价成交价 |
| `volume` | 成交量，单位手 |
| `trade_amount_yuan` | 按成交量计算的成交额 |
| `status_raw` / `side` | 原始状态 / 方向 |

## 使用建议

如果要看竞价阶段过程，用 [7709-集合竞价明细.md](7709-集合竞价明细.md) 或 `client.trades.auction_today()` / `auction_history()`；如果只要 09:25 最终撮合，按当日或历史选择本页对应入口。
