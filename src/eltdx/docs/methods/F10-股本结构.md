# F10-股本结构

## 作用

查询股本结构、股本变动、股票回购和限售流通数据，由 `client.f10.capital_structure()` 的 `section` 参数分派。5 个分区中 `restricted_detail` 必须显式传日期。

| 项目 | 内容 |
| --- | --- |
| 调用方法 | `client.f10.capital_structure(code, section="structure", *, date=None)` |
| 底层 Entry | [`CWServ.tdxf10_gg_gbjg`](../F10_7615.md#entry-cwserv-tdxf10-gg-gbjg)；`restricted_detail` 走 [`CWServ.tdxf10_gg_gbjg_xsjjmx`](../F10_7615.md#entry-cwserv-tdxf10-gg-gbjg-xsjjbg) |
| 返回模型 | `F10Response` |

## 分区（section）

| section | 中文分区 | 需要额外参数 |
| --- | --- | --- |
| `structure` | 股本结构 | — |
| `changes` | 股本变动 | — |
| `buyback` | 股票回购 | — |
| `restricted` | 限售流通 | — |
| `restricted_detail` | 限售解禁明细 | **必须传 `date`（`YYYYMMDD`）** |

`date` 只被 `restricted_detail` 使用；其它分区传了也不会改变请求。

## 示例

```python
from eltdx import F10Client

f10 = F10Client(timeout=3)

structure = f10.capital_structure("688004")
buyback = f10.capital_structure("688004", "buyback")
detail = f10.capital_structure("688004", "restricted_detail", date="20260101")

print(structure.rows[:3])
print(buyback.rows[0])
print(detail.entry, detail.rows[:3])
```

缺 `date` 时会立刻报错，不会静默退回别的分区：

```python
f10.capital_structure("688004", "restricted_detail")
# ValueError: capital_structure section 'restricted_detail' requires date (YYYYMMDD)
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `section` | 分区，见上表，默认 `structure` |
| `date` | 解禁日期 `YYYYMMDD`，仅 `restricted_detail` 使用，必填 |

## 请求对照

```python
Entry = "CWServ.tdxf10_gg_gbjg"
# structure  {"Params": ["688004", "gbjg"]}
# changes    {"Params": ["688004", "gbbd"]}
# buyback    {"Params": ["688004", "gphg"]}
# restricted {"Params": ["688004", "xslt"]}

Entry = "CWServ.tdxf10_gg_gbjg_xsjjmx"
# restricted_detail {"Params": ["688004", "20260101"]}
```

## 字段对照

| section | 常用字段 |
| --- | --- |
| `structure` | `T002` 截止日期、`T003` 总股本、`T004` 已流通股份、`T011` 无限售条件流通股、`T019` 流通股份合计 |
| `changes` | `T002` 变动日期、`T003` 变动后总股本、`T004` 变动前总股本、`T006`/`T007` 变动数量与比例、`T008` 变动原因码 |
| `buyback` | `N001` 公告日、`N002` 进度、`N005` 已回购数量、`N006` 已回购占比%、`N007` 回购均价、`N009`/`N010` 回购起止日、`N021` 回购用途 |
| `restricted` | `T003` 解禁日、`T004` 解禁市值、`T010` 解禁数量、`T012` 状态、`T014` 解禁数量（万股）、`T006` 股份来源 |
| `restricted_detail` | `T003` 解禁日、`T004` 解禁数量、`T007` 股东名称、`T011` 公告日、`xsyy` 解禁原因、`cur` 查询日期 |

`structure` / `changes` / `restricted` 会返回多张表：第一张是主表，其它表是口径说明或附加统计。需要看全部表时用：

```python
for table in response.tables:
    print(table.key, table.columns, table.rows[:2])
```

适合做股本演变、回购进度和解禁压力分析。
