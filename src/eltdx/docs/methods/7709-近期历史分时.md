# 7709-近期历史分时

## 作用

查询服务端近期窗口内的历史分时。它和 `0x0fb4` 都是历史分时，但覆盖范围以服务端近期窗口为准。

| 项目 | 内容 |
| --- | --- |
| 主要调用 · 单只 | `client.minutes.recent(code, trading_date=None)` → `MinuteSeries` |
| 代码列表 | `client.minutes.recent([code1, code2], trading_date=None, batch_size=...)` → `dict[str, MinuteSeries]` |
| 底层接口 | [`0x0feb`](../COMMANDS_7709.md#cmd-0x0feb) |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    series = client.minutes.recent("sz000001", "2026-05-20")
    series_by_code = client.minutes.recent(
        ["sz000001", "sh600000"], "2026-05-20", batch_size=8
    )
```

不传日期时使用当前日期：

```python
with TdxClient(timeout=3) as client:
    today_like = client.minutes.recent("sz000001")
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 单个证券代码或代码列表；支持完整代码或六位代码 |
| `trading_date` | 近期窗口内的交易日；不传时使用当前日期 |
| `include_raw` | 是否保留原始 payload，默认 `False` |
| `batch_size` | 代码列表输入时的同时查询数，默认自动跟随连接池大小 |

## 解析字段

| `MinuteSeries` 字段 | 含义 |
| --- | --- |
| `exchange` / `market_id` / `code` / `full_code` | 市场和代码 |
| `trading_date` | 请求指定的交易日，由客户端填入 |
| `prev_close` | 昨收 |
| `open_price` | 今开 |
| `date_selector_raw` | 请求中使用的日期选择器原始值 |
| `reserved_zero` | 响应头保留字段 |
| `points` | 分时点列表 |
| `count` | 分时点数量 |
| `volume_sum` | 分时成交量合计 |
| `raw_payload` | 原始 payload |

| `MinutePoint` 字段 | 含义 |
| --- | --- |
| `index` | 分时序号 |
| `time_label` / `time` | 时间文本 / 带日期时间 |
| `price` / `price_milli` | 分时价格 / 千分价格单位 |
| `avg_price` | 均价 |
| `volume` | 分钟成交量，单位手 |
| `price_field` / `avg_field` | 协议中的价格字段 / 均价字段 |
| `price_raw` / `avg_raw` | 还原后的原始价格口径 |
| `price_delta_raw` / `aux_delta_raw` | 协议价格差分 / 辅助差分原始值；近期接口可能为 `None` |
| `record_hex` | 单条原始十六进制 |

## 覆盖范围

`0x0feb` 是近期窗口接口，能查多久由服务端决定；需要查更早日期时，用 [7709-指定日期历史分时.md](7709-指定日期历史分时.md)。

## 实测结果

修复日期编码后，用 `client.minutes.recent("sz000988", "2026-11-25")` 请求近期分时，返回的开盘价和最后一个分时点的价格与当日日线一致。

服务端响应不带可独立校验的交易日期。排查历史数据时，可以用同一天的日线与分时序列对照。已发布的 3.3.6 和 3.4.0-beta.3 仍使用旧编码，回查指定日期时可用 [指定日期历史分时](7709-指定日期历史分时.md)。
