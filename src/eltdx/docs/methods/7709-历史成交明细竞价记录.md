# 7709-历史成交明细竞价记录

## 作用

从历史成交明细 `0x0fc6` 中筛选指定交易日的集合竞价记录，只保留 `status=8` 的竞价事件。它是成交明细里的分钟记录，不是 `0x056a` 返回的秒级竞价过程快照，也不代表实际成交。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.trades.auction_history(code, date, ...)` |
| 底层接口 | [`0x0fc6`](../COMMANDS_7709.md#cmd-0x0fc6) |
| 返回模型 | `tuple[TradeTick, ...]` |
| 时间字段 | 只有分钟级时间，没有秒字段 |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    records = client.trades.auction_history("sz000001", "2026-05-20")

for record in records:
    print(record.time_label, record.price, record.auction_matched_volume)
```

## 返回示例

接口返回 `tuple[TradeTick, ...]`。单条记录示例：

```python
if records:
    record = records[0]
    result = {
        "time": record.time_label,
        "price": record.price,
        "volume": record.volume,
        "order_count": record.order_count,
        "matched_volume": record.auction_matched_volume,
        "unmatched_signed_volume": record.auction_unmatched_signed_volume,
        "event_kind": record.event_kind,
    }
    print(result)
```

示例结果：

```python
{
    "time": "09:24",
    "price": 10.52,
    "volume": 18300,
    "order_count": -4200,
    "matched_volume": 18300,
    "unmatched_signed_volume": -4200,
    "event_kind": "auction_snapshot",
}
```

## 返回字段

| 字段 | 含义 |
| --- | --- |
| `index` / `absolute_index` | 页内序号 / 成交明细中的全局序号 |
| `time_minutes` | 当日分钟数，例如 `564` 表示 `09:24` |
| `time_label` | 时间文本；本接口只有分钟，不含秒 |
| `trade_datetime` | 指定交易日的成交时间 |
| `price` / `price_milli` | 竞价价格 / 毫厘价格 |
| `volume` | 原始数量字段，在竞价记录中表示虚拟匹配量，单位手 |
| `order_count` | 原始笔数字段，在竞价记录中表示带符号未匹配量 |
| `auction_matched_volume` | 虚拟匹配量，单位手 |
| `auction_unmatched_signed_volume` | 带方向的未匹配量，单位手 |
| `auction_unmatched_volume` | 未匹配量绝对值，单位手 |
| `event_kind` | 固定为 `auction_snapshot` |
| `is_auction_snapshot` | 是否为竞价快照，固定为 `True` |
| `status_raw` / `side` | 原始状态 / 方向解析结果 |
| `trade_amount_yuan` | 按 `price * volume * 100` 估算的金额，不代表实际成交金额 |
| `record_hex` | 单条记录的原始十六进制内容 |

## 解析规则

只返回 `status_raw == 8` 的记录。`volume` 是虚拟匹配量，`order_count` 是带符号未匹配量，`trade_amount_yuan` 只是按价格和数量估算的金额，不代表已经成交。

常用字段包括 `time_label`、`price`、`volume`、`order_count`、`auction_matched_volume`、`auction_unmatched_signed_volume`、`auction_unmatched_volume`、`event_kind` 和 `record_hex`。

如果需要 09:25 正式撮合，请使用 [历史 09:25 正式撮合](7709-历史0925正式撮合.md)。
