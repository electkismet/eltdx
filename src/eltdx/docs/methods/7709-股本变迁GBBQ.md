# 7709-股本变迁GBBQ

## 作用

查询广义股本变迁 / 权息资料，原样返回标签 `1..15`，包括除权除息、送配股上市、股本变化、增发、回购、缩股、权证和重整调整等记录。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.corporate.capital_changes(code, *, include_raw=False, batch_size=75)` |
| 底层接口 | [`0x000f`](../COMMANDS_7709.md#cmd-0x000f) |
| 单只返回 | `CapitalChangeBlock` |
| 批量返回 | `CapitalChangeBatch` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    block = client.corporate.capital_changes("sz000001")
    batch = client.corporate.capital_changes(["sz000001", "sh600000", "bj920000"])
```

遍历事件：

```python
for item in block.records:
    print(item.date, item.category_name, item.c1_value, item.c2_value, item.c3_value, item.c4_value)
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `include_raw` | 是否保留原始 payload |
| `batch_size` | 列表输入时每个逻辑批次的代码数，默认 `75`，范围 `1..200` |

`code` 可以是一个代码字符串，也可以是代码列表。列表默认按每批 `75` 只自动拆分，支持深圳、上海和北交所代码混合传入。`batch_size` 可调整为 `1..200`；多个批次按底层连接池的 Slot 数并发执行，结果仍按批次和服务端块顺序合并。

主站还可能因为单次解压响应较大，只返回本批代码列表的一个前缀。SDK 会检查实际返回的股票块并继续请求剩余代码；因此即使把 `batch_size` 调到 `200`，一次逻辑批次也可能产生多次补拉请求。

默认客户端使用最快 2 台主站、每台 4 条连接，共 8 个 Slot。大量股票拆出的批次可以分散到这些连接；单个 `0x000f` 批次始终是一个请求，只占用一个 Slot。

## 解析字段

| `CapitalChangeBlock` 字段 | 含义 |
| --- | --- |
| `exchange` / `market_id` / `code` / `full_code` | 市场和代码 |
| `block_count` | 服务端块数量 |
| `records` / `items` | 事件列表 |
| `count` | 实际记录数 |
| `raw_payload` | 原始 payload |

`CapitalChangeBatch.blocks` 保存每只股票的 `CapitalChangeBlock`，`count` 是返回的股票块数，`records` 是所有块的事件记录扁平视图。`include_raw=True` 时，每个协议批次的原始响应保存在 `raw_payloads`。

| `CapitalChangeBatch` 字段 | 含义 |
| --- | --- |
| `blocks` | 每只股票一个 `CapitalChangeBlock` |
| `records` | 所有股票事件记录的扁平视图 |
| `count` | 股票块数量 |
| `raw_payloads` | 各协议批次的原始响应；未启用 `include_raw` 时为空 |

| `CapitalChangeRecord` 字段 | 含义 |
| --- | --- |
| `exchange` / `market_id` / `code` / `full_code` | 市场和代码 |
| `reserved_7` | 保留字节 |
| `date_raw` | 事件日期原始值，形如 `YYYYMMDD` |
| `date` | 事件日期 |
| `category_raw` / `category` | 事件类别编号 |
| `category_name` | 类别名称 |
| `c1_raw` / `c2_raw` / `c3_raw` / `c4_raw` | 四个原始字段 |
| `c1_float` / `c2_float` / `c3_float` / `c4_float` | 四个字段按 float32 解释的值 |
| `c1_value` / `c2_value` / `c3_value` / `c4_value` | 按类别解码后的四个业务值 |
| `c1` / `c2` / `c3` / `c4` | `c1_value` 到 `c4_value` 的简写属性 |
| `record_hex` | 单条原始十六进制 |
| `time` | 事件日期派生出的 `15:00` 时间 |

## 类别表

| `category_raw` | `category_name` | 参数口径 |
| ---:| --- | --- |
| `1` | 除权除息 | `c1=每十股现金分红 D`、`c2=配股价格 P`、`c3=每十股送转数量 S`、`c4=每十股配股数量 R` |
| `2` | 送配股上市 | 股本数量类字段 |
| `3` | 非流通股上市 | 股本数量类字段 |
| `4` | 未知股本变动 | 保留 raw，避免套用未验证的字段语义 |
| `5` | 股本变化 | 股本数量类字段，可用于整理流通股本 / 总股本 |
| `6` | 增发新股 | `c2_value` 为发行价，`c3_value` 为已转换成“股”的发行数量；`c1/c4` 保留原始值 |
| `7` | 股份回购 | 股本数量类字段 |
| `8` | 增发新股上市 | 股本数量类字段 |
| `9` | 转配股上市 | 股本数量类字段 |
| `10` | 可转债上市 | 股本数量类字段 |
| `11` | 扩缩股 | float32 比例类字段 |
| `12` | 非流通股缩股 | float32 比例类字段 |
| `13` | 送认购权证 | float32 权证类字段 |
| `14` | 送认沽权证 | float32 权证类字段 |
| `15` | 重整调整 | float32 比例类字段，样本里 `c3` 可和 F10 的转增显示对齐 |

## 单位口径

类别 `1/4/11/12/13/14/15` 按 float32 原值解释。类别 `2/3/5/7/8/9/10` 的四个 wire 字段是万股口径，`c*_value` 统一乘 `10000` 转为股数。类别 `6` 是混合口径：`c2_value` 保持元价格，`c3_value` 将万股转换为股数，`c1/c4` 保持原值。

`record+0x0C` 是事件标签，不是有效标志。`capital_changes()` 不筛选标签；只有本地复权系数计算会选取标签 `1`。标签 `2/3/5/7/8/9/10` 描述股本变化，不应再次参与基础价格复权。

真实配股样本 `000858 / 20010219` 的四字段为 `0, 25, 0, 2`，即不分红、配股价 25 元、不送转、每 10 股配 2 股。该样本确认了标签 `1` 的字段顺序。
