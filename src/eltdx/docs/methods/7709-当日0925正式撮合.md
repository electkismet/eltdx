# 7709-当日 09:25 正式撮合

## 作用

从当日成交明细 `0x0fc5` 中筛选 09:25 的正式开盘撮合记录。该接口返回实际撮合记录，不会把 `status=8` 的竞价过程快照当作成交。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.trades.opening_match_today(code, ..., batch_size=None)` |
| 底层接口 | [`0x0fc5`](../COMMANDS_7709.md#cmd-0x0fc5) |
| 返回模型 | `TradeTick | None` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    opening = client.trades.opening_match_today("sz000001")
    openings = client.trades.opening_match_today(["sz000001", "sh600000"])

if opening is not None:
    print(opening.time_label, opening.price, opening.volume, opening.trade_amount_yuan)
```

## 返回示例

接口返回单个 `TradeTick`；找不到记录时返回 `None`。

```python
if opening is not None:
    result = {
        "time": opening.time_label,
        "price": opening.price,
        "volume": opening.volume,
        "side": opening.side,
        "event_kind": opening.event_kind,
        "trade_amount_yuan": opening.trade_amount_yuan,
    }
    print(result)
```

示例结果：

```python

    "time": "09:25",
    "price": 10.58,
    "volume": 25600,
    "side": "neutral",
    "event_kind": "opening_match",

```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 单个证券代码或代码列表；支持完整代码或六位代码 |
| `include_raw` | 是否保留原始响应和记录十六进制，默认 `False` |
| `page_size` | 内部扫描成交明细时的每页条数，默认 `1800`，范围 `1..1800` |
| `max_pages` | 内部扫描最大页数，默认 `100`；传 `None` 表示不设上限 |
| `batch_size` | 代码列表输入时的同时查询数，默认自动跟随连接池大小；代码列表没有总数量上限，超出并发数的代码排队等待。 |

## 返回字段

| 字段 | 含义 |
| --- | --- |
| `index` / `absolute_index` | 页内序号 / 成交明细中的全局序号 |
| `time_minutes` / `time_label` | 当日分钟数 / 固定为 `09:25` |
| `trade_datetime` | 成交时间；当日接口通常为 `None` |
| `price` / `price_milli` | 正式撮合价 / 毫厘价格 |
| `volume` | 正式撮合成交量，单位手 |
| `order_count` | 原始笔数字段 |
| `event_kind` | 固定为 `opening_match` |
| `is_opening_match` | 是否为 09:25 正式撮合，固定为 `True` |
| `status_raw` / `side` | 原始状态 / 方向解析结果 |
| `price_delta_raw` / `price_acc_raw` | 价格差分及累计原始值 |
| `unknown_tail_raw` / `reserved_zero` | 协议尾部字段，可能为 `None` |
| `auction_matched_volume` / `auction_unmatched_signed_volume` | 竞价专用字段；正式撮合接口通常为 `None` |
| `trade_amount_yuan` | 按 `price * volume * 100` 计算的成交额 |
| `record_hex` | 单条记录的原始十六进制内容 |

找不到 09:25 正式撮合时返回 `None`。
