# 行情订阅接口

订阅一组股票，行情更新时自动调用 `callback(record)`。客户端负责分组、维护游标和每 7 秒续期。

```python
client.quotes.subscribe(codes, callback)
```

## 开始订阅

```python
from eltdx import TdxClient


def on_quote(record):
    print(record.full_code, record.last_price)


with TdxClient(pool_size=1) as client:
    sub = client.quotes.subscribe(["sh600000", "sz000001"], on_quote)
    sub.run()  # 持续接收，按 Ctrl+C 退出
```

`subscribe()` 返回 `QuoteSubscription` 句柄，调用 `run()` 后开始订阅。初始行情、续期返回的增量和服务端主动推送都会触发回调；退出时自动释放占用的连接。需要运行指定时长时，使用 `sub.run(duration=60)`；从其他线程停止时，调用 `sub.stop()`。

## 订阅参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `codes` | 必填 | 单个代码或代码列表，例如 `"sh600000"`；自动标准化并去重 |
| `callback` | 必填 | 每条行情记录调用一次，接收 `QuoteRefreshRecord` |
| `timeout` | `0.5` | 单次等待推送的最长时间，单位秒 |
| `reactivate_interval` | `7.0` | 订阅续期间隔，单位秒；`None` 禁用自动续期 |
| `on_error` | `None` | 续期、读取或回调出错时的处理函数；未设置则抛出异常 |
| `filter_codes` | `True` | 只派发本次订阅代码的行情 |

`subscribe_hq()` 是 `subscribe()` 的别名，参数和行为相同。

## 订阅更多股票

每个连接最多订阅 100 只股票。超过后自动分组，每组独占一个连接；1,000 只股票需要至少 10 个连接：

```python
with TdxClient(pool_size=10) as client:
    codes = [record.full_code for record in client.codes.a_shares("sh")][:1000]
    client.quotes.subscribe(codes, on_quote).run(duration=60)
```

- `pool_size` 至少为去重后股票数除以 100 并向上取整；不足时，激活前抛出 `ValueError`。
- 同一客户端使用一个订阅管理全部关注代码。如果还要同时执行其他查询，请预留额外连接。
- 回调同步执行，应及时返回。耗时任务可交给调用方自己的工作队列。

## 回调数据

回调每次收到一个 `QuoteRefreshRecord`，常用字段如下：

| 字段 | 含义 |
| --- | --- |
| `full_code` | 标准证券代码 |
| `last_price` / `last_close_price` | 最新价 / 昨收价 |
| `open_price` / `high_price` / `low_price` | 开盘价 / 最高价 / 最低价 |
| `total_hand` / `current_hand` | 总成交量 / 现量，单位手 |
| `amount` | 成交额 |
| `buy_levels` / `sell_levels` | 买卖盘口；每档有 `price`、`volume` 等字段 |
| `update_time_raw` | 服务端行情更新时间，客户端自动用于续期 |

## 进阶用法

??? example "手动控制接收循环"
    先 `activate()` 获取初始行情，再调用 `run_once()` 接收并派发。结束时必须 `close()` 释放连接。

    ```python
    sub = client.quotes.subscribe(["sh600000"], on_quote)
    try:
        page = sub.activate()  # 初始结果由调用方处理，本方法不触发回调
        for record in page.records:
            on_quote(record)
        while not sub.stopped:
            sub.run_once()
    finally:
        sub.close()
    ```

??? info "单次刷新与推送队列"
    需要自行管理刷新和接收时，可以使用以下方法；持续订阅直接使用上面的 `subscribe()`。

    | 方法 | 用途 |
    | --- | --- |
    | `client.quotes.get_depth(codes)` | 一次获取实时五档，等价于首次游标为零的刷新 |
    | `client.quotes.refresh(codes, cursors=...)` | 按代码和游标发起一次增量刷新，返回 `QuoteRefreshPage` |
    | `client.quotes.poll_push(timeout=0.5, parse=True)` | 读取一帧推送并解析；无数据时返回 `None` |
    | `client.quotes.drain_pushes(parse=True)` | 取出队列中当前已有的推送帧 |

    单次 `refresh()` / `get_depth()` 最多接受 100 个代码。`refresh()` 的直接响应由返回值交付，后续服务端主动推送进入队列；订阅句柄会统一派发这两类记录。

    底层命令为 [`0x0547`](../COMMANDS_7709.md#cmd-0x0547)。需要一次基础快照可使用 [`get_snapshots()`](7709-批量快照.md)（`0x054c`）；旧版完整快照使用 [`legacy()`](7709-旧版批量行情.md)（`0x053e`），三个命令的模型和解析器不能互换。

??? info "续期游标与运行边界"
    每只股票首次使用游标 `0`，之后采用该股票最后收到的 `update_time_raw`，例如 `102851 → 102857 → 102906`。它是服务端日内时间，不使用 `active` 或本机时间作为游标；次日早盘收到较小值时也会更新。较旧的记录可能导致补发部分增量，调用方可按业务规则处理重复。

    每组订阅始终在原连接上续期。普通心跳不能替代续期；禁用自动续期后，服务端可能在一段时间后停止推送。推送频率和覆盖取决于主站及交易时段。断线后需由调用方重新建立订阅，`on_error` 仅接收错误。

    同一客户端的推送队列由一个订阅统一读取，避免多个消费者互相取走记录。刷新请求使用 `0x0029xxxx` 消息编号，非零序号用于请求响应配对，`0x00290000` 用于服务端推送。每个连接槽最多分配 65,535 次刷新请求，耗尽时显式报错，需创建新客户端。

??? info "完整返回字段"
    | `QuoteRefreshPage` 字段 | 含义 |
    | --- | --- |
    | `requested_codes` | 请求代码 |
    | `records` | 增量行情记录 |
    | `decoded_payload` | 解码后的 payload |
    | `raw_payload` | 原始 payload |
    | `count` | 记录数 |

    | `QuoteRefreshRecord` 字段 | 含义 |
    | --- | --- |
    | `exchange` / `market_id` / `code` / `full_code` | 市场和代码 |
    | `active` | 活跃序号 / 状态序号 |
    | `update_time_raw` | 更新时间原始值 |
    | `last_price` / `last_close_price` | 最新价 / 昨收价 |
    | `open_price` / `high_price` / `low_price` | 今开 / 最高 / 最低 |
    | `status_or_reserved_raw` | 状态 / 保留原始字段 |
    | `total_hand` / `current_hand` | 总量 / 现量，单位手 |
    | `amount` / `amount_raw` | 成交额 / 成交额原始值 |
    | `inside_dish` / `outer_disc` | 内盘 / 外盘，单位手 |
    | `unknown_after_outer_raw` | 外盘后保留字段 |
    | `open_amount_raw` / `open_amount_yuan` | 开盘金额原始值 / 开盘金额 |
    | `buy_levels` / `sell_levels` | 刷新记录中的盘口字段；首次刷新建立五档基线，后续由推送更新 |
    | `tail_raw` | 尾部原始字段 |
    | `record_hex` | 单条记录原始十六进制 |

    `buy_levels` / `sell_levels` 单档是 `QuoteLevel`，字段为 `price`、`volume`、`price_delta_raw`。
