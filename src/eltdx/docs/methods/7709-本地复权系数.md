# 7709-本地复权系数

## 作用

根据 `0x000f` 权息资料和完整不复权日 K，在本地计算每天的前复权、后复权仿射系数。该接口用于审计、研究或本地行情库；普通复权 K 线直接使用 `client.bars.get(..., adjust="qfq" / "hfq")` 让主站计算。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.corporate.adjustment_factors(code, anchor_date=None)` |
| 底层数据 | `0x000f` + `0x052d` 不复权日 K 自动分页 |
| 返回模型 | `AdjustmentFactorResponse` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    factors = client.corporate.adjustment_factors("sz000858")
    anchored = client.corporate.adjustment_factors("sz000858", anchor_date="2024-06-03")

item = factors.items[0]
qfq_close = round(raw_close * item.qfq_scale + item.qfq_offset, 2)
hfq_close = round(raw_close * item.hfq_scale + item.hfq_offset, 2)
```

现金分红和配股会产生加法项，因此结果不是单一乘数。必须同时使用 `scale` 和 `offset`：

```text
adjusted = round(raw * scale + offset, 2)
```

## 单次事件公式

标签 `1` 的字段含义：

```text
D = c1_value  每十股现金分红
P = c2_value  配股价格
S = c3_value  每十股送转数量
R = c4_value  每十股配股数量

m = (10 + S + R) / 10
c = (D - R * P) / 10
```

单次前复权：

```text
adjusted = (raw - c) / m
```

单次后复权：

```text
adjusted = m * raw + c
```

例如 `000858 / 20010219` 的字段是 `0, 25, 0, 2`，得到 `m=1.2`、`c=-5`：

```text
前复权 = (raw + 5) / 1.2
后复权 = raw * 1.2 - 5
```

## 多次事件规则

| 模式 | 事件范围 | 顺序 |
| --- | --- | --- |
| 前复权 | `K线日期 < 除权日 <= 锚点日期` | 日期从早到晚 |
| 后复权 | `首个交易日 <= 除权日 <= K线日期` | 日期从晚到早 |

同一天有多条事件时保持服务端原始顺序。上市首个交易日之前的预发行记录会被排除。只有标签 `1` 参与价格复权，股本变化类标签不会重复计入。

事件复合和系数保存阶段不舍入；将系数应用到 OHLC 后再统一保留两位小数。`anchor_date` 用于前复权截止日：若不是交易日，取该日期之前最近的交易日；早于首个可用交易日会抛出 `ValueError`。后复权系数不受锚点影响。

## 返回字段

| `AdjustmentFactorResponse` | 含义 |
| --- | --- |
| `exchange` / `market_id` / `code` / `full_code` | 市场和代码 |
| `anchor_date` | 实际采用的前复权锚点；未指定时为 `None` |
| `first_trading_date` | 完整不复权日 K 的首个交易日 |
| `items` / `count` | 每个交易日的系数及数量 |

| `AdjustmentFactor` | 含义 |
| --- | --- |
| `date` / `time` | 交易日及其 `15:00` 时间 |
| `qfq_scale` / `qfq_offset` | 前复权仿射系数 |
| `hfq_scale` / `hfq_offset` | 后复权仿射系数 |

本接口只返回系数，不返回另一套本地复权 K 线。需要 K 线时，取不复权数据后按 `raw * scale + offset` 应用，或直接请求主站复权数据。
