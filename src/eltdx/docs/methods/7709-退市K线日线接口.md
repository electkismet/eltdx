# 7709-退市 K 线（日线、不复权）

## 作用

查询退市股票的不复权日线，支持单只或批量查询、自动分页。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.delisted_bars.get(code, ...)` |
| 底层接口 | [`0x052b`](../COMMANDS_7709.md#cmd-0x052b) |
| 返回模型 | 单只：`KlineSeries`；批量：`dict[str, KlineSeries]` |
| 单页上限 | `800` 根 |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3, pool_size=3) as client:
    # 查询最近 800 根日线
    page = client.delisted_bars.get("T000038", count=800)
    # 自动翻页获取历史日线
    history = client.delisted_bars.get("T000038", all_pages=True)
    # 一次查询多只，每只股票独立翻页
    histories = client.delisted_bars.get(
        ["T000038", "002087", "sh600001"], all_pages=True, batch_size=3
    )
    for code, series in histories.items():
        print(code, series.count)
    first_history = histories["sz000038"]
```

代码支持 `T000038`、`sz000038` 和 `000038` 三种写法。

`code` 传字符串时返回一个 `KlineSeries`；传列表或元组时返回字典，键为 `sz000038`、`sh600001` 等标准代码。批量结果保留输入顺序，相同股票的不同代码写法会合并，只查询一次；空列表会报错。`batch_size` 控制同时查询多少只股票，实际并发不超过 `pool_size`，默认随连接池容量。任一股票查询失败时，整次调用会抛出异常。

`all_pages=False`（默认）查询一页；`all_pages=True` 自动向前翻页，直到返回空页。每页不足 `page_size` 根时也会继续查询，合并后的 `bars` 按日期升序排列，保留所有记录，不自动去重。达到 `max_pages` 仍未收到空页时，抛出 `RuntimeError`。可查询的历史范围取决于主站保存的数据。

手动分页时，`start=0` 从最新数据开始；下一页的 `start` 为上一页起点加实际返回根数。

## 参数

<div class="api-parameters" markdown="1">

| 参数 | 类型 | 默认值 | 怎么填 |
| --- | --- | --- | --- |
| `code` | 字符串、列表或元组 | 必填 | 单只填 `"T000038"`、`"sz000038"` 或 `"000038"`；多只填 `["T000038", "002087", "sh600001"]` |
| `period` | 字符串 | `"day"` | 查询日线时可省略；支持 `"day"`、`"1d"`、`"d"`、`"daily"` |
| `start` | 整数 | `0` | 从最新数据开始；手动查下一页时，加上上一页实际返回根数。范围 `0..65535` |
| `count` | 整数 | `800` | 单页请求根数，例如 `20`，范围 `1..800`；仅在 `all_pages=False` 时使用 |
| `adjust` | 字符串或 `None` | `None` | 查询不复权日线时可省略，也可填 `"none"` |
| `include_raw` | 布尔值 | `False` | 填 `True` 保留 `raw_payload` 和每条 `record_hex`；填 `False` 只取解析结果 |
| `all_pages` | 布尔值 | `False` | 填 `True` 自动翻页直到空页；填 `False` 只取 `start/count` 指定的一页 |
| `page_size` | 整数 | `800` | 自动分页每页请求根数，范围 `1..800`；通常保持默认，仅在 `all_pages=True` 时使用 |
| `max_pages` | 整数或 `None` | `200` | 每只股票最多请求页数；达到上限仍未收到空页会报错。填 `None` 不设页数上限，分页起点仍须在 `start` 的范围内；仅在 `all_pages=True` 时使用 |
| `batch_size` | 整数或 `None` | `None` | 同时查询的股票数，例如 `3`；填 `None` 随连接池容量，填 `1` 顺序查询。须为正整数，实际并发不超过 `pool_size` |

</div>

`True`、`False` 和 `None` 都使用 Python 值，无需加引号。

例如，只查询最近 20 根日线和自动获取历史日线分别写为：

```python
page = client.delisted_bars.get("T000038", all_pages=False, count=20)
history = client.delisted_bars.get("T000038", all_pages=True)
```

## 返回字段

单只返回 `KlineSeries`，批量返回 `{标准代码: KlineSeries}`。每个结果的 `bars` 为 `KlineBar` 序列，`count` 为日线根数。`period_name="day"`，`adjust_mode="none"`。批量开启自动分页时，`start`、`page_size` 和 `max_pages` 分别应用于每只股票。

| 字段 | 含义 |
| --- | --- |
| `time` | 交易日期，以上海时区当天 `00:00` 表示 |
| `open` / `close` / `high` / `low` | 不复权开高低收价格，单位元 |
| `volume_raw` / `volume_wire_value` | 成交量，单位股 |
| `volume_lots` | 手数，股数除以 `100` |
| `amount` | 成交额，单位元 |
| `last_close_price_milli` | 同页前一条记录的收盘毫厘价；每页首条为 `None` |
| `record_hex` | `include_raw=True` 时保留单条记录的原始十六进制 |
| `raw_payload` | `include_raw=True` 时保留原始响应；自动分页时仅保留第一页的原始响应 |

默认 `include_raw=False` 时 `record_hex=""`、`raw_payload=b""`。若需要逐页原文，请使用 `start/count` 手动分页。

普通证券的多周期和复权查询见 [K 线 / 周期线](7709-K线周期线.md)。
