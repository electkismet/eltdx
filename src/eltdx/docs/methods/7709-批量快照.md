# 7709-批量快照

## 作用

按显式代码列表直接调用一次 `0x054c` 基础快照，返回现价、涨跌幅、成交量额、内外盘和已确认的一档盘口。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.quotes.get_snapshots(codes)` |
| 底层接口 | [`0x054c`](../COMMANDS_7709.md#cmd-0x054c) |
| 返回模型 | `list[QuoteSnapshot]` |

这个方法按给定代码列表返回当前行情快照。涨幅榜、成交额榜这类服务端排序列表使用 [7709-分类行情.md](7709-分类行情.md)。

## 与 `0x0547`、`0x053e` 的区别

`0x054c` 的核心定位是**无游标的一次性基础快照**，用于建立一批代码的当前行情基线。

- 它不负责 `0x0547` 的五档刷新和推送；普通用户需要完整行情时使用独立的 [完整行情 / 五档盘口](../helpers/完整行情.md) Helper。
- 它不是 `0x053e`：`0x053e` 是旧版完整快照，一次返回五档、交易状态和旧版尾部原始字段。
- `0x0547` 的原生入口统一见 [增量刷新 / 推送队列](7709-增量刷新推送队列.md)；`client.quotes.legacy()` 才是 `0x053e` 旧版完整快照入口。

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    quotes = client.quotes.get_snapshots(["sz000001", "sh600000"])
    quote = quotes[0]
    print(quote.last_price, quote.change_pct)
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `codes` | 单个代码或代码列表，支持 `sz000001`、`000001` 这类写法；没有市场前缀时会按代码段补全 |

`client.quotes.get_snapshots()` 只发送一次 `0x054c` 请求，盘口只返回当前已确认的一档。它不会自动请求 `0x0547`，也不会读取推送队列。

## 解析字段

| `QuoteSnapshot` 字段 | 含义 |
| --- | --- |
| `exchange` | 市场前缀，`sz` / `sh` / `bj` |
| `market_id` | 市场编号，`0=sz`、`1=sh`、`2=bj` |
| `code` | 六位代码 |
| `full_code` | 完整代码，`exchange + code` |
| `active1` | 活跃序号 / 状态序号，原样保留 |
| `last_price` | 最新价 / 现价 |
| `pre_close_price` | 昨收价 |
| `open_price` | 今开价 |
| `high_price` | 最高价 |
| `low_price` | 最低价 |
| `time_raw` | 行情时间原始值 |
| `unknown_after_time_raw` | 时间后保留字段，原样保留 |
| `total_hand` | 总成交量，单位手 |
| `current_hand` | 现手 |
| `amount` | 成交额 |
| `amount_raw` | 成交额 compact-float 原始值 |
| `inside_dish` | 内盘，单位手 |
| `outer_disc` | 外盘，单位手 |
| `unknown_after_outer_raw` | 外盘后保留字段，原样保留 |
| `open_amount_raw` | 开盘金额原始值 |
| `open_amount_yuan` | 开盘金额，单位元 |
| `buy_levels` / `sell_levels` | 当前实盘 `0x054c` 稳定确认为买一 / 卖一 |
| `tail_raw` | 尾部扩展原始字段 |

`buy_levels` / `sell_levels` 单档是 `QuoteLevel`：

| `QuoteLevel` 字段 | 含义 |
| --- | --- |
| `price` | 档位价格 |
| `volume` | 档位挂单量，单位手 |
| `price_delta_raw` | 相对现价的价格差分原始值 |

## 派生字段

| 字段 | 计算方式 |
| --- | --- |
| `change` | `last_price - pre_close_price` |
| `change_pct` | `change / pre_close_price * 100` |
| `sum_buy_vol` | 五档买量合计 |
| `sum_sell_vol` | 五档卖量合计 |

## 使用建议

| 场景 | 建议 |
| --- | --- |
| 普通业务查询完整行情 | 用 [`client.helpers.full_quotes(...)`](../helpers/完整行情.md) |
| 只调用原生基础快照 | 用 `client.quotes.get_snapshots(...)` |
| 直接操作五档刷新或推送 | 用 [`client.quotes.get_depth()` / `refresh()`](7709-增量刷新推送队列.md) |
| 查涨幅榜 / 成交额榜 | 用 `client.quotes.list_by_category()` |
| 实时连续刷新可见代码 | 先用快照初始化，再配合 `client.quotes.refresh()` |

`0x054c` 返回的是当前行情快照，不包含分时曲线、成交明细、K 线历史。那些数据分别用分时、成交明细和 K 线方法取。
