# F10-板块与指数

## 作用

查询板块 F10（`880xxx`）、指数 F10（如 `399001`）和大盘指数 F10（`000001`）。三者**共用 `client.f10.market_report()` 一个方法**，靠 `section` 分派到不同的 Entry 家族：

| 标的类型 | 代码示例 | Entry 家族 | 页面目录 |
| --- | --- | --- | --- |
| 板块 | `880472` | `CWServ.skef10_bk_*` | `sketchf10/zsf10/` |
| 指数 | `399001` | `CWServ.skef10_zs_*` | `sketchf10/zsf10/` |
| 大盘指数 | `000001` | `CWServ.skef10_dpzx_*` | `sketchf10/dpzxf10/` |

传错标的类型不会报错，只是服务端返回空表——例如 `section="board_info"` 传 `399001`，或 `section="index_info"` 传 `880472`。

| 项目 | 内容 |
| --- | --- |
| 调用方法 | `client.f10.market_report(code, section="board_info", *, arg="", date=None, page=1, page_size=20)` |
| 底层 Entry | [`CWServ.skef10_bk_getinfo`](../F10_7615.md#entry-cwserv-skef10-bk-getinfo) 等 `CWServ.skef10_bk_*` / `skef10_zs_*` / `skef10_dpzx_*` |
| 返回模型 | `F10Response` |

## 分区（section）

| section | 中文分区 | `arg` 默认值 | 适用标的 |
| --- | --- | --- | --- |
| `board_info` | 板块名称与市场 | — | 板块 |
| `board_basics` | 板块基础资料 | `001` | 板块 |
| `board_description` | 板块说明 | `002` | 板块 |
| `board_trading` | 板块交易数据 | `004` | 板块 |
| `board_flow` | 板块资金 | `001_1`（`002_1`/`003_1` 可切换口径） | 板块 |
| `board_members` | 成份股数据 | `001`（`002`～`005` 可切换表） | 板块 |
| `board_analysis` | 板块三点分析 | `001` | 板块 |
| `board_finance_compare` | 成份股财务对比 | — | 板块 |
| `board_candidates` | 成份股候选数据 | `001`/`002` | 板块 |
| `board_trend` | 板块异动分析 | — | 板块 |
| `index_info` | 指数信息 | — | 指数 |
| `index_profile` | 指数概况 | — | 指数 |
| `index_tracking` | 跟踪标的 | — | 指数 |
| `index_flow` | 指数资金动向 | `004_1`（`003`/`004_2` 可切换） | 指数 |
| `index_flow_members` | 成份股资金 | `001` | 指数 |
| `index_notices` | 今日提示 | `001` | 指数 |
| `market_basic` | 大盘指数基本信息 | — | 大盘 |
| `market_margin` | 大盘两融 | — | 大盘 |
| `market_new_shares` | 新股分析 | — | 大盘（不需要 `code`） |
| `market_capital` | 大盘市场概览 | `004`（`001`～`004` 可切换） | 大盘（不需要 `code`） |

`market_new_shares` 与 `market_capital` 不传 `code`，签名里的 `code` 会被忽略；`page` / `page_size` 只对集合类分区（`board_members`、`index_tracking`、`index_flow` 等）有效。

## 示例

```python
from eltdx import F10Client

f10 = F10Client(timeout=3)

board = f10.market_report("880472", "board_info")
members = f10.market_report("880472", "board_members", page_size=20)
index = f10.market_report("399001", "index_info")
market = f10.market_report("000001", "market_basic")

print(board.rows[0])
print(members.rows[:3])
print(index.rows[0])
print(market.rows[0])
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 板块 / 指数 / 大盘指数代码；`market_new_shares`、`market_capital` 不需要 |
| `section` | 分区，见上表，默认 `board_info` |
| `arg` | 分区附加参数（口径 / 表号 / 排序键），如 `board_flow` 的 `001_1` |
| `date` | 保留参数，当前没有分区使用 |
| `page` / `page_size` | 页码 / 每页条数，默认 `1` / `20` |

## 字段对照

| section | 常用字段 |
| --- | --- |
| `board_info` | `T003` 板块代码、`T004` 板块名称、`sc` 市场 |
| `board_basics` | `N001` 流通市值、`N002` 总市值、`N003` 换手率%、`N004` 市盈率、`N005`/`N006` 涨跌幅、`N009`/`dm` 权重股、`N012` 报告期 |
| `board_description` | `N012` 日期、`N013` 板块类型、`N014` 板块简介、`N002`～`N006` 成份股要点 |
| `board_trading` | `N001` 交易日、`N002` 板块指数、`N003` 成交额、`N004`/`N005` 上涨与下跌家数、`N006`～`N010` 各区间涨跌幅 |
| `board_flow` | `N001` 交易日、`N004` 名称、`N005` 主力净额、`N006`～`N010` 分档净额 |
| `board_members` | `N001` 代码、`N002` 名称、`sc` 市场、`N003` 分红方案、`N004` 进度、`N005`～`N007` 关键日期、`N008` 报告期 |
| `board_analysis` | `N001`～`N010` 三点分析指标、`N011` 统计日期 |
| `board_finance_compare` | `dm`/`N002` 代码与名称、`N001` 报告期、`N003`～`N011` 财务对比指标 |
| `board_candidates` | `N001`～`N010` 候选数据；无数据时为空表 |
| `board_trend` | `ct` 异动家数、`ct_Z` / `ct_D` 分类家数 |
| `index_info` | `T001` 指数代码、`T003` 指数名称、`T010` 品种类型 |
| `index_profile` | `N001` 指数全称、`N002` 代码、`N005` 发布日期、`N006` 基点、`N007` 基期、`N011` 样本数、`N012`/`N013` 编制说明 |
| `index_tracking` | `N001` 基金代码、`N002` 基金名称、`sc` 市场、`N003` 规模、`N009` 基金经理、`N010` 基金公司 |
| `index_flow` | `N001` 日期、`N002` 成交额、`N003` 净流入、`N004` 资金规模 |
| `index_flow_members` | `N001` 成分股代码、`N002` 名称、`N003` 日期、`N004` 标记 |
| `index_notices` | `N001` 代码、`N002` 名称、`N003` 分红方案、`N004` 类型、`N005`～`N007` 关键日期 |
| `market_basic` | 见上方示例的 `N001`～`N009` |
| `market_margin` | `N001` 日期、`N002` 代码、`N003` 名称、`N004` 融资余额、`N005` 融券余额、`N006` 占流通市值%、`N008`/`N009` 附加金额 |
| `market_new_shares` | `N001` 日期、`N002` 代码、`N003` 名称、`N004` 发行价、`N005` 发行市盈率、`N007` 中签率、`N008` 募资额 |
| `market_capital` | `N001` 代码、`N002` 名称、`N003` 方案说明、`N004` 进度 |

板块分区常返回 1～3 张表，全部表可用：

```python
for table in response.tables:
    print(table.key, table.columns, table.rows[:2])
```

适合做板块资金与成份股分析、指数编制信息查询和大盘两融 / 新股统计。
