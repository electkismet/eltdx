# 7709-集合竞价过程快照

## 作用

查询主站保存的当日或历史集合竞价过程快照，包括价格、虚拟匹配量、未匹配量等。每条记录带秒字段，通常几秒一条；它是专用的竞价快照接口，不是逐笔成交接口。

使用标准连接池时，当日和历史查询统一使用 `money_flow_servers.json` 中的 35 台主站，不再按日期选择普通主站列表。默认创建客户端时即完成两组主站测速，集合竞价和资金流向共享 35 台的内存排名；各自首次请求时才创建业务连接并握手，此后不重复测速。两组专用池沿用客户端的超时和并发配置，关闭客户端时一并释放；`probe_hosts=False` 可跳过测速，其他接口和自定义非池化 transport 的路由不变。历史数据覆盖范围仍以主站实际保存的数据为准。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.auctions.series(code, date=None)` |
| 底层接口 | [`0x056a`](../COMMANDS_7709.md#cmd-0x056a) |
| 返回模型 | `AuctionSeries` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    today = client.auctions.series("sz000001")
    history = client.auctions.series("sz000001", "2026-06-12")

    for point in history.points:
        print(point.time_label, point.price, point.matched_volume)
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `date` | 不传时查询主站当前交易日；传入 `date`、`YYYYMMDD` 整数或 `YYYY-MM-DD` 字符串时查询该历史日期 |
| `include_raw` | 是否保留原始 payload，默认 `False` |

不传日期时，请求日期字段为 `0`；传入日期时，请求日期字段为 `YYYYMMDD`。凌晨、周末或节假日不传日期时，主站可能仍返回最近交易日数据。

接口不限制时间范围，不按固定时间范围过滤、截断或去重，而是按主站响应顺序返回全部记录。不同股票和市场的最后一个上午时间点可能是 `09:24:57`、`09:24:59`、`09:25:00`，也可能稍晚；还可能包含尾盘集合竞价过程。即使过程数据中出现 `09:25`，它仍然是虚拟撮合快照，不能当作正式成交。正式撮合应使用 [当日 09:25 正式撮合](7709-当日0925正式撮合.md) 或 [历史 09:25 正式撮合](7709-历史0925正式撮合.md)。

尾盘集合竞价通常从 `14:57` 开始，可能持续到 `15:00` 附近。`0x056a` 与成交明细中的 `status=8` 可在分钟和价格上对应，但本接口额外提供秒、虚拟匹配量和未匹配量，是竞价过程分析的权威入口。成交明细中的 `status=8` 只作为原始简化快照保留，不应使用其数量字段替代本接口。

## 解析字段

| `AuctionSeries` 字段 | 含义 |
| --- | --- |
| `exchange` / `market_id` / `code` / `full_code` | 市场和代码 |
| `trading_date` | 请求的历史日期；不传日期时为 `None` |
| `mode_or_selector_raw` | 模式 / 选择器原始值 |
| `start_raw` | 起始参数原始值 |
| `limit_or_count_raw` | 数量参数原始值 |
| `points` | 竞价明细记录 |
| `count` | 记录数 |
| `raw_payload` | 原始 payload |

| `AuctionPoint` 字段 | 含义 |
| --- | --- |
| `index` | 序号 |
| `minute_of_day_raw` | 当日分钟原始值 |
| `second_raw` | 秒原始值 |
| `time_label` | 时间 |
| `time_seconds` | 当日秒数 |
| `price` / `price_milli` | 竞价价格 / 毫厘价 |
| `matched_volume` | 虚拟匹配量，单位手，不代表已经发生的逐笔成交 |
| `unmatched_signed_raw` | 未匹配量带符号原始值 |
| `unmatched_volume` | 未匹配量，单位手 |
| `unmatched_direction_raw` | 未匹配方向原始值 |
| `reserved_zero_0e` | 保留字段 |
| `record_hex` | 单条原始十六进制 |
| `matched_amount_estimated` | 估算成交额，`price * matched_volume * 100` |

## 和成交明细接口的区别

| 方法 | 数据来源 | 适合场景 |
| --- | --- | --- |
| `client.auctions.series(code, date=None)` | `0x056a` 集合竞价快照 | 看当日或指定历史日期的竞价阶段价格、虚拟匹配量、未匹配量过程 |
| `client.trades.today(code)` / `all_today(code)` | `0x0fc5` 当日成交明细 | `ticks` 保留 `status=8` 简化快照；`actual_trades` 排除快照并保留真实成交 |
| `client.trades.history(code, trading_date)` / `all_history(code, trading_date)` | `0x0fc6` 历史成交明细 | 指定日期的原始混合记录、真实成交和盘后固定价格成交视图 |
| `client.trades.opening_match_today(code)` / `opening_match_history(code, trading_date)` | `0x0fc5` / `0x0fc6` 成交明细 | 分别读取当日 / 历史 `event_kind="opening_match"` 的 09:25 正式撮合，见对应独立文档 |
