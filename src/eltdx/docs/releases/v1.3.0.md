# v1.3.0

`v1.3.0` 将 MCP 服务迁移到 MCP Python SDK 2，并扩充行情、竞价、短线指标、题材和 F10 工具。服务提供 17 个 tools 和 8 个内置文档 resources。

## 五档盘口边界

`0x0547` 实盘主站单次最多返回 100 个代码。请求 101 个及以上代码时，主站只返回前 100 条且不报告截断。为避免静默丢数据，以下入口现在统一限制单次最多 100 个代码：

- `client.quotes.refresh()`
- `client.quotes.get_depth()`
- `client.get_quote_depth()`
- MCP `eltdx_quote_depth`

普通 `client.get_quote()` 和 MCP `eltdx_quote` 仍可一次接收最多 200 个代码；客户端会按 80 个代码自动拆批，不受这个单次协议限制。

## MCP 并发与复用

- 行情客户端按 `host + timeout` 复用，同一配置只执行一次首次初始化。
- 同一配置固定使用 4 个连接槽位。多个工具线程通过 `PooledSocketTransport` 分配到空闲 TCP 连接，最多 4 个行情请求同时在途，不会直接共用同一个 socket；更多请求按 FIFO 等待。
- 不同配置的首次连接可以并行，一个慢主站不会阻塞其他主站或 F10 工具。
- 最多保留 16 个行情客户端；达到上限时关闭并淘汰最久未使用的空闲客户端。
- F10 使用独立 HTTP 调用，不占用行情客户端槽位。
- MCP 退出时等待在途行情调用完成后再关闭连接，临时关闭失败可以重试清理。

## 安装

```bash
pip install "eltdx[mcp]==1.3.0"
eltdx-mcp
```

源码开发：

```bash
pip install -e ".[dev,mcp]"
python -m pytest
```
