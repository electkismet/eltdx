# v3.0.7

`v3.0.7` 是跨语言 HTTP / WebSocket 网关的兼容性补丁版本。

## 主要变化

- 保留 `v3.0.6` 引入的 HTTP JSON、WebSocket RPC 和原生 `0x0547` 行情订阅能力。
- 普通 `pip install eltdx` 仍不安装 FastAPI/Uvicorn，也不会启动额外服务。

## 修复内容

- 修复 Python 3.10 下访问 `GET /methods` 时，方法枚举可能读取到无效 slots 描述符并抛出 `TypeError` 的问题。
- 方法枚举改为逐项安全读取公开成员，Python 3.10-3.14 返回一致的方法列表。
- 同步 README 版本化横幅与赞助图位置测试。

## 安装和平台

本版本支持 CPython 3.10-3.14，使用 `cp310-abi3` 产物：Windows x64、Linux x64、Linux ARM64、macOS x64 和 macOS ARM64 五个独立 ABI3 wheel，另有一个源码包。

```bash
python -m pip install --upgrade "eltdx==3.0.7"
```

## 升级注意

使用 FastAPI 网关的用户建议从 `v3.0.6` 升级：

```bash
python -m pip install --upgrade "eltdx[http]==3.0.7"
eltdx-http
```

普通 Python API、MCP、7709 和 7615 接口没有行为变化。
