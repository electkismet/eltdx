# v3.1.1

`v3.1.1` 为 7709 资金流向接口增加独立主站池，并整理当前版本的协议回归测试。

## 主要变化

- `client.money_flow.daily(...)` 使用 35 台已验证的 IPv4 `7709` 主站。
- 普通行情接口继续使用默认主站列表，现有调用方式不变。
- 资金流主站池采用懒连接，首次调用资金流接口时才测速和建立连接。
- `client.bars.get()` 默认按代码自动识别股票或指数；指数代码使用正确的 K 线布局并解析上涨 / 下跌家数。

## 修复内容

- 避免资金流请求落到连接成功但返回空资金字段的普通行情主站。
- 修复指数 K 线未显式传入 `kind` 时按股票布局解析的问题（覆盖 `sh000`、`sh880`、`sh881`、`sh999`、`sz399`、`bj899` 代码）。

## 测试

- 协议回归使用仓库内当前 7709 golden fixture，不需要下载或安装旧版本 wheel。
- 公共接口结构测试以 3.1.1 当前 API 为准，不再锁定旧版本字段列表。

## 升级注意

现有 API 保持兼容。升级后无需修改代码；资金流接口会自动使用独立主站池。

```bash
python -m pip install --upgrade "eltdx==3.1.1"
```
