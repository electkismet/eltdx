# v2.0.3

`v2.0.3` 是相对 `v2.0.2` 的修复版本，不新增或删除公开接口。

## 修复说明

- `client.helpers.auction_data(include_snapshot=False)` 不再在当前交易日额外请求 09:25 正式撮合。
- 成交明细手动分页遇到短页时不再提前结束；`TradePage.has_more` 会一直保持为真，直到主站返回空页。
- 修复包版本测试仍断言 `2.0.1` 导致 CI 失败的问题。
- 修复 wheel 冒烟脚本仍按 17 个 MCP 工具检查的问题；当前 MCP 服务提供 20 个工具和 8 个文档资源。
- 更新 README 接口目录横幅、当前版本导航和 Helpers 目录数量说明。

`client.quotes.legacy()` 对应的 `0x053e`、`client.resources.read()` 对应的 `0x06b9`，以及 `v2.0.2` 的其他模块化入口均保持不变。

## 安装

```bash
pip install -U "eltdx==2.0.3"
```
