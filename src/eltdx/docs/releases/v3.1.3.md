# v3.1.3

`v3.1.3` 增加批量 K 线查询和连板天梯 F10 接口，保持已有行情、连接池和 MCP 调用兼容。

## 主要变化

- `client.bars.get()` 的 `code` 支持单个代码或代码列表；列表查询按连接池并发执行，返回以规范化完整代码为键的字典。
- 新增 `batch_size` 参数限制 K 线批量并发数；单代码调用的返回类型和分页行为保持不变。
- 新增 `client.f10.limit_board_ladder(start_date, end_date, include_summary=False)`，对接 `CWServ.cfg_fx_lbtt`，支持单日、日期范围和默认当天查询。
- 新增 `LimitBoardLadder`、`LimitBoardLadderRow` 模型以及 MCP 工具 `eltdx_limit_board_ladder`。
- 补充连板天梯字段映射、F10 Entry 说明、接口目录和包内文档镜像。

## 修复内容

- 批量 K 线输入统一执行代码规范化和去重，避免同一证券重复请求。
- 连板天梯响应保留原始字段，同时提供交易日、市场、完整代码、连板级别、封单金额等结构化字段。

## 测试

- 全量 Python 测试通过，覆盖批量 K 线并发、F10 连板天梯解析、MCP 工具和文档页面契约。
- `ruff` 和 `mkdocs build --strict` 通过。

## 升级注意

现有单代码 K 线和其他 F10 调用无需修改。需要批量查询时，把 `code` 传入代码列表；需要连板天梯明细时调用新的 `client.f10.limit_board_ladder()`。

```bash
python -m pip install --upgrade "eltdx==3.1.3"
```
