# v3.1.9

`v3.1.9` 修复无前缀证券代码的市场识别。

- `920xxx` 正确识别为北交所（`bj`）。
- `900xxx` 继续识别为上海 B 股（`sh`）。
- 精度元数据加载与统一代码规范化规则保持一致。

```python
from eltdx.protocol.unit import normalize_code

assert normalize_code("920001") == "bj920001"
assert normalize_code("900901") == "sh900901"
```
