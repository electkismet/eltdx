# v3.0.6

`v3.0.6` 增加可选的 FastAPI 跨语言网关，让 Java、Go、C#、Node.js 等语言可以调用 `eltdx` 的公开接口。

## 主要变化

- 新增 `eltdx-http` 命令和 `eltdx[http]` 可选依赖。
- `POST /rpc` 通过统一 JSON RPC 调用公开的 `TdxClient` API。
- `WebSocket /ws` 支持同样的 RPC 调用，并提供 `quotes.subscribe` / `quotes.unsubscribe`。
- `quotes.subscribe` 桥接原生 `0x0547` 行情增量，先返回五档基线，再推送主站后续更新。
- HTTP 与 WebSocket 共用同一套 `TdxClient` 和 7709 连接池；网关支持多个 7709 主站和连接池并发配置。
- 新增 `/health`、`/methods` 和 FastAPI `/docs` 入口。

## 修复内容

- 修复网关请求体和 WebSocket 参数在 FastAPI 延迟导入场景下的类型解析。
- 修复行情推送拥堵时可能影响普通 RPC 响应的问题；普通响应使用独立可靠队列。
- 增加跨语言网关的订阅、取消订阅、发行包和文档镜像回归测试。

## 安装和平台

本版本支持 CPython 3.10-3.14，使用 `cp310-abi3` 产物：Windows x64、Linux x64、Linux ARM64、macOS x64 和 macOS ARM64 五个独立 ABI3 wheel，另有一个源码包。

```bash
python -m pip install --upgrade "eltdx==3.0.6"
```

## 升级注意

普通 Python 用户继续安装：

```bash
python -m pip install --upgrade "eltdx==3.0.6"
```

默认安装不会安装 FastAPI 或 Uvicorn，也不会启动额外服务。需要跨语言网关时再安装：

```bash
python -m pip install --upgrade "eltdx[http]==3.0.6"
eltdx-http
```

详细请求格式、WebSocket 订阅和启动参数见 [跨语言 HTTP / WebSocket 网关](../HTTP_GATEWAY.md)。
