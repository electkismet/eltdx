# v3.0.8

`v3.0.8` 更新每日涨跌停价计算和 MCP 工具。

## 主要变化

- `client.helpers.daily_price_limits()` 必须传入 `trade_date`。
- 参考价取 T 日之前最近一根不复权日线，停牌时使用最近实际成交日线。
- 返回 `pre_close_trade_date` 和 `pre_close_source`，明确参考价日期和来源。
- 当日除权除息事件按 `0x000f` 标签 1 应用于参考价。
- 主板 ST/*ST 按 2026 年 7 月 6 日起实施的 10% 规则计算。

## MCP

新增 `eltdx_daily_price_limits`，`trade_date` 为必填参数。

## 修复内容

- 不再用实时快照替代缺失的历史日线，缺失时返回明确状态。
- 明确输出参考日线日期、来源和规则。

## 安装和平台

本版本支持 CPython 3.10-3.14，使用 `cp310-abi3` 产物：Windows x64、Linux x64、Linux ARM64、macOS x64 和 macOS ARM64 五个独立 ABI3 wheel，另有一个源码包。

## 安装

```bash
python -m pip install --upgrade "eltdx==3.0.8"
```

## 升级注意

使用 MCP 或每日涨跌停价接口的用户升级到 `3.0.8` 后，调用 `daily_price_limits` 时必须传入 `trade_date`。
