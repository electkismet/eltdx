# v1.3.1

`v1.3.1` 是 `v1.3.0` 的兼容性补丁版本，修复北交所六位代码的市场推断，并完善 MCP 自定义行情主站的输入校验和失败回滚。

## 北交所代码推断

不带市场前缀的六位北交所股票代码以 `92` 开头。此前通用的上海 `9xxxxx` 规则先于北交所规则匹配，导致 `920001` 被错误规范化为 `sh920001`。

本版本改为先匹配更具体的 `92xxxx` 规则：

```python
from eltdx.protocol.unit import normalize_code

assert normalize_code("920001") == "bj920001"
assert normalize_code("900901") == "sh900901"
```

上海 `900xxx` B 股的识别保持不变。产品仍主要面向 A 股研究，底层代码规范化继续保留对通达信其他证券品种的正确识别。为避免无前缀代码的市场歧义，调用时仍推荐传 `sz000001`、`sh600000`、`bj920001` 这类完整代码。

## MCP 主站校验与回滚

- MCP 行情工具的自定义 `host` 必须使用 `host:port` 格式，端口范围为 1 到 65535。
- 非法主站会在创建和登记行情客户端前直接失败，不会留下 pending key。
- 如果客户端构造本身失败，registry 会回滚 pending key 并唤醒同配置等待者，后续请求不会永久等待。

## 安装

```bash
pip install -U "eltdx==1.3.1"
```

需要 MCP 支持时：

```bash
pip install -U "eltdx[mcp]==1.3.1"
eltdx-mcp
```

## 兼容性

- 原有带市场前缀的行情、K 线、分时、成交、竞价、F10 和 Helpers 调用不变。
- `900xxx` 仍识别为上海 B 股；仅修正此前错误的无前缀 `92xxxx` 推断。
- 合法的 IPv4、域名和 IPv6 `host:port` 配置继续支持。
