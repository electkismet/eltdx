# v3.2.0

## 主要变化

- F10 请求默认先尝试 IPv4 地址，连接失败后继续尝试其他地址，包括 IPv6；仅有 IPv6 的域名仍可连接。
- 新增 `F10Client(prefer_ipv4=False)` 选项，可恢复系统默认地址顺序。
- 此策略只作用于 F10 的 HTTP/HTTPS 连接，不修改全局 DNS 函数，不将并发 F10 请求串行化。保留 urllib 的环境代理、HTTP Host、HTTPS SNI 和证书校验。

## 修复内容

- 减少域名同时有 A/AAAA 记录、IPv6 路由不通而 IPv4 正常时的等待。地址连接仍依次尝试并使用 `timeout`；本版本未实现 IPv4/IPv6 并行竞速，也不保证请求总耗时不超过 `timeout`。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.2.0"
```
