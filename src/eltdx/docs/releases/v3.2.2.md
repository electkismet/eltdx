# v3.2.2

## 主要变化

- `client.helpers.board_quotes()` 默认返回概念板块。
- 新增 `category` 参数，支持 `概念`、`风格`、`地区`、`880行业`、`一级行业`、`二级行业`、`三级行业` 和 `全部`。
- 补充分类字段、行业编码和板块行情接口文档。

## 使用示例

```python
with TdxClient(timeout=3) as client:
    concepts = client.helpers.board_quotes()
    industries = client.helpers.board_quotes(category="二级行业")
    all_boards = client.helpers.board_quotes(category="全部")
```

## 修复内容

- 修正板块行情默认范围过大的问题，避免无参数调用直接请求全部板块定义。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.2.2"
```
