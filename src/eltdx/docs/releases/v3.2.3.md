# v3.2.3

## 主要变化

- 新增 `client.delisted_bars.get()`，查询退市股票的不复权日线。
- 支持 `T000038`、`sz000038` 和 `000038` 等代码写法；传入列表或元组可一次查询多只股票。
- `all_pages=True` 自动翻页，批量查询时每只股票独立翻页，合并结果按日期升序排列。
- 批量返回 `{标准代码: KlineSeries}`，相同股票的不同代码写法只查询一次；可通过 `batch_size` 控制并发。
- 更新接口说明、参数填写示例和返回样本，改善手机参数表的显示。

## 使用示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3, pool_size=3) as client:
    history = client.delisted_bars.get("T000038", all_pages=True)
    histories = client.delisted_bars.get(
        ["T000038", "002087", "sh600001"],
        all_pages=True,
        batch_size=3,
    )
    for code, series in histories.items():
        print(code, series.count)
```

当前支持日线、不复权。可查询的历史范围取决于主站保存的数据。参数和返回字段见[退市 K 线接口](../methods/7709-退市K线日线接口.md)。

## 修复内容

- `max_pages` 严格要求正整数或 `None`，拒绝布尔值、小数、NaN、无穷大及其他无效值；无效参数在查询前报错。
- 批量代码校验拒绝全角等非半角数字，避免已经查询部分股票后才发现无效代码。股票代码数字须使用半角 `0-9`。
