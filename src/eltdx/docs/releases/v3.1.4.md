# v3.1.4

`v3.1.4` 修正涨跌停列表解析并补充更直观的接口名称、市场概况和梯队统计，兼容已有 API。

## 主要变化

- `client.f10.limit_up_down_list(start_date, end_date, include_summary=False)` 提供涨停、炸板、跌停列表。
- 新增 `highest_board_level`、`status`、`reason` 字段，板位使用服务端 `lbts`，最高板摘要使用 `zglb`。
- 新增 `market_overview`、`ladder_counts`、`promotion_rates`，日期范围按交易日提供 `*_by_date` 统计。
- 新增 MCP 工具 `eltdx_limit_up_down_list`；`limit_board_ladder` 与对应 MCP 工具保留兼容。

## 修复内容

- 修复此前将当天最高板 `zglb` 误当作每只股票板位的问题。
- 保持批量 K 线、连接池测速和既有 F10 调用行为不变。

## 测试

- Python 测试与 MCP、文档契约测试通过；`ruff check src tests` 通过。

## 升级注意

原有调用无需修改；推荐使用 `client.f10.limit_up_down_list()` 获取涨跌停列表。

```bash
python -m pip install --upgrade "eltdx==3.1.4"
```
