# 成交对比

获取当前交易日与前一交易日累计成交量对比的分钟副图。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.volume_comparison(code, include_raw=False)` |
| 返回 | `MinuteAuxSeries` |
| 数据来源 | `0x051b` 分时副图 |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    series = client.helpers.volume_comparison("sz000001")
    print(series.rows[-1])
```

序列用于观察两日累计成交量差异，不替代 `client.trades` 的原始或真实成交视图。
