# 最新停牌列表

获取当前交易状态为停牌的 A 股证券。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.latest_suspended(market=None)` |
| 返回 | `list[SecurityCode]` |
| 数据来源 | `0x044d` 代码表 + `0x053e` 交易状态位 `0x20` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    rows = client.helpers.latest_suspended()
```

这是当前状态扫描，不是历史停牌日期表。`market` 可选 `sh`、`sz` 或 `bj`。
