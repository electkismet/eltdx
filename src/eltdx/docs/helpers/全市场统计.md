# 全市场涨跌统计

## 作用

一次性给出 A 股全市场的涨跌统计概况：上涨 / 下跌 / 平盘 / 停牌家数、总家数、总成交额、总成交量、总市值以及涨停 / 跌停家数。

数据来自主站的统计指数 `sh880005`（涨/跌/平/总家数）、`sh880001`（总市值）、`sh880006`（涨停/跌停家数），通过一个 `0x053e` 旧版批量行情请求一次取回。统计指数把计数编码在价格字段里，按 1/10 缩放，因此计数用 `round(值 * 10)` 还原。

## 调用

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.market_stat()` |
| 底层接口 | `0x053e`（[旧版批量行情](7709-旧版批量行情.md)） |
| 返回 | `MarketStat` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    stat = client.helpers.market_stat()
    print("上涨", stat.up_count, "下跌", stat.down_count, "平盘", stat.neutral_count)
    print("涨停", stat.limit_up_count, "跌停", stat.limit_down_count)
    print("成交额", stat.total_amount)
```

## 返回字段

| 字段 | 含义 |
| --- | --- |
| `up_count` | 上涨家数 |
| `down_count` | 下跌家数 |
| `neutral_count` | 平盘家数 |
| `suspended_count` | 由 `total - up - down - neutral` 推算，近似停牌 / 未参与统计家数 |
| `total_count` | 总家数（含停牌） |
| `total_amount` | 总成交额 |
| `total_volume` | 总成交量 |
| `total_market_cap` | 总市值（元），来自 `880001`，乘 1e10 还原 |
| `limit_up_count` | 涨停家数 |
| `limit_down_count` | 跌停家数 |

## 使用说明

| 项目 | 说明 |
| --- | --- |
| 请求 | 只发一次 `0x053e`，代码固定为 `sh880005` / `sh880001` / `sh880006` |
| 停牌家数 | 为推算值，`max(0, total - up - down - neutral)` |
| 无数据 | 主站未返回任何行情时抛 `RuntimeError` |
| 缓存 | 不缓存；每次调用都请求主站 |
