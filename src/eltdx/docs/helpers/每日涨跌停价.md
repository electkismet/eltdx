# 每日涨跌停价

按实时昨收、市场板块、ST 和新股规则计算标准化涨跌停价格。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.daily_price_limits(codes=None)` |
| 返回 | `DailyPriceLimitTable` |
| 数据来源 | `0x054c` 昨收 + 本地业务规则 |

## 返回字段

每行 `DailyPriceLimit` 包含 `full_code`、`trade_date`、`pre_close`、`limit_up_price`、`limit_down_price` 和 `limit_rule`。

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    table = client.helpers.daily_price_limits(["sz000001", "sh600000"])
    for row in table.rows:
        print(row.full_code, row.limit_up_price, row.limit_down_price)
```

这是业务计算结果，不是服务器独立的“每日涨跌停价”协议。除权除息、ST、新股和板块规则按当前模型处理。
