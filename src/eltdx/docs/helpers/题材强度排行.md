# 题材强度排行

按个股 F10 题材聚合涨停数量、最高板、连板数和封单金额。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.theme_strength_rank(codes=None, count=None)` |
| 返回 | `ThemeStrengthTable` |
| 数据来源 | 连板天梯 + 7615 F10 题材 |

## 返回字段

每行 `ThemeStrengthRow` 包含 `topic_id`、`topic_name`、`limit_up_count`、`highest_ladder_level`、`lianban_count`、`total_seal_amount` 和代表股 `leader`。

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    table = client.helpers.theme_strength_rank(count=20)
    for row in table.rows:
        print(row.topic_name, row.limit_up_count, row.highest_ladder_level)
```

该接口会读取候选股票的 F10 题材，适合盘后或小范围候选，不建议在每秒刷新循环中调用。
