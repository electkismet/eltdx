# 板块行情与成分股

本页提供两个独立接口：一个查询全部板块自身行情，一个查询指定板块的成分股行情。两者都只在调用时取行情，不会在后台自动运行。

## 1. 查询全部板块行情

### 接口

```python
client.helpers.board_quotes(*, refresh=False) -> BoardQuoteTable
```

### 作用

读取板块定义文件，按文件原始顺序返回每个板块自身的实时行情。接口不排序、不筛选，也不会读取成分股列表。

### 输入参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `refresh` | `bool` | 否 | `False` | 是否强制重新准备当天的板块资料和证券名单。普通调用保持默认值即可。 |

该接口没有板块代码参数，因为它返回全部板块。板块数量由定义文件实际解析结果决定，不写死为某个数量。

### 底层请求与批量规则

- `0x06b9`：准备/更新板块资料文件。
- `0x044d`：准备当天有效证券名单，用于资料准备阶段。
- `0x054c`：查询板块自身行情。
- 行情请求按每批最多 80 个代码拆分，内部自动完成，调用方不需要手动分批。

### 返回值

返回 `BoardQuoteTable`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `rows` | `tuple[BoardQuoteRow, ...]` | 按板块定义文件顺序排列的行情行。 |
| `count` | `int` | `rows` 的数量。 |
| `prepared_date` | `date` | 本次使用的板块资料日期。 |

每行 `BoardQuoteRow` 字段：

| 字段 | 含义 |
| --- | --- |
| `board_code` | 六位板块代码 |
| `board_name` | 板块名称 |
| `full_code` | 带市场前缀的行情代码，例如 `sh880515` |
| `last_price` / `pre_close_price` | 最新价 / 昨收 |
| `change` / `change_pct` | 涨跌额 / 涨跌幅 |
| `amount` / `volume_hand` | 成交额 / 成交量（手） |
| `quote` | 原始 `QuoteSnapshot`，需要底层字段时使用 |

### 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    table = client.helpers.board_quotes()
    print(table.count, table.prepared_date)
    for row in table.rows[:10]:
        print(row.board_code, row.board_name, row.change_pct)
```

## 2. 查询指定板块的成分股行情

### 接口

```python
client.helpers.board_member_quotes(
    board_code: str,
    *,
    refresh=False,
) -> BoardMemberQuoteTable
```

### 作用

传入一个板块代码，读取该板块的原始成分股，与当天 `0x044d` 有效证券名单核对后，只为有效成分股查询实时行情。

### 输入参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `board_code` | `str` | 是 | 无 | 六位板块代码，例如 `"880515"`；也接受带市场前缀的完整代码，例如 `"sh880515"`。 |
| `refresh` | `bool` | 否 | `False` | 是否强制重新准备当天的板块资料和证券名单。 |

### 处理步骤与底层请求

1. 用 `0x06b9` 准备板块资料。
2. 根据板块代码解析原始成分股。
3. 用 `0x044d` 当前证券名单核对有效性。
4. 对有效成员按每批最多 80 个代码调用 `0x054c`。

### 返回值

返回 `BoardMemberQuoteTable`：

| 字段 | 含义 |
| --- | --- |
| `board_code` / `board_name` | 请求板块的代码和名称 |
| `raw_members` | 文件中解析出的原始成员，不手工删除 |
| `display_members` | 与当天 `0x044d` 名单匹配后的有效成员 |
| `excluded_members` | 原始成员中当前名单不存在的记录及排除原因 |
| `rows` | 有效成员的行情行，顺序与 `display_members` 一致 |
| `count` | `rows` 的数量 |
| `prepared_date` | 本次使用的板块资料日期 |

`raw_members`、`display_members` 和 `excluded_members` 的每项至少包含 `market`、`code`；排除项额外包含 `reason`。`rows` 中每项为 `BoardQuoteRow`，其中 `full_code` 是带市场前缀的证券代码。

### 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    table = client.helpers.board_member_quotes("880515")
    print(table.board_name, table.count)
    print("原始成员:", len(table.raw_members))
    print("有效成员:", len(table.display_members))
    print("排除成员:", table.excluded_members)
    for row in table.rows:
        print(row.full_code, row.last_price, row.change_pct)
```

### 输入错误

- `board_code` 为空或不是字符串：抛出 `ValueError("board_code is required")`。
- 找不到对应板块代码：抛出 `ValueError("unknown board code: ...")`。
- 板块资料不完整或类别不支持：抛出 `ValueError` 或 `RuntimeError`，调用方应记录错误并检查本地资料目录。

## 当天缓存规则

第一次调用任一板块 Helper 时准备资料：当天没有成功记录就下载 `infoharbor_block.dat`、`tdxhy.cfg`，并读取三市场 `0x044d` 代码表；成功后在数据目录写入 `.eltdx_board_cache.json`。这一步只准备资料，不代表已经请求了所有板块成分股行情。

同一天后续调用复用本地资料和名单，不会重复下载或重复读取 `0x044d`。新的一天会重新准备；传入 `refresh=True` 可显式强制重新准备。数据目录可通过 `ELTDX_BOARD_DATA_DIR` 指定，默认使用当前工作目录下的 `downloads`。

板块资料文件自身的修改时间不作为业务日期判断依据，日期以服务端握手日期为准。

## 排序

这两个接口都不负责排序。调用方可以根据 `change_pct`、`amount` 等字段自行排序；如果需要服务端分类排序，应使用 `client.quotes.list_by_category()`（`0x054b`）。
