# 板块行情与成分股

板块行情提供两个按需调用的 Helper：

```python
with TdxClient(timeout=3) as client:
    boards = client.helpers.board_quotes()
    members = client.helpers.board_member_quotes("880515")
```

## 板块自身行情

`client.helpers.board_quotes(refresh=False)` 读取本地板块定义，按定义文件中的原始顺序返回板块行情。接口不排序、不筛选，也不调用成分股行情。

每批最多 80 个板块，底层调用 `0x054c`。板块数量以本地定义文件实际解析出的数量为准，不写死数量。

每行 `BoardQuoteRow` 常用字段：

| 字段 | 含义 |
| --- | --- |
| `board_code` | 六位板块代码 |
| `board_name` | 板块名称 |
| `full_code` | 带市场前缀的行情代码，例如 `sh880515` |
| `last_price` / `pre_close_price` | 最新价 / 昨收 |
| `change` / `change_pct` | 涨跌额 / 涨跌幅 |
| `amount` / `volume_hand` | 成交额 / 成交量（手） |
| `quote` | 原始 `QuoteSnapshot`，需要底层字段时使用 |

## 板块成分股行情

`client.helpers.board_member_quotes(board_code, refresh=False)` 必须传入板块代码，只查询该板块的成分股。

处理流程：

1. 读取 `0x06b9` 下载或本地缓存的板块资料。
2. 解析板块原始成员。
3. 用 `0x044d` 当前证券代码表按 `market + code` 核对有效成员。
4. 对有效成员按每批 80 个调用 `0x054c`。

返回的 `BoardMemberQuoteTable` 保留三组成员信息：

| 字段 | 含义 |
| --- | --- |
| `raw_members` | 文件中解析出的原始成员，不手工删除 |
| `display_members` | 与当天 `0x044d` 名单匹配后的有效成员 |
| `excluded_members` | 原始成员中当前名单不存在的记录及排除原因 |
| `rows` | 有效成员的行情行，顺序与有效成员一致 |

## 当天缓存规则

第一次调用任一板块 Helper 时准备资料：当天没有成功记录就下载 `infoharbor_block.dat`、`tdxhy.cfg`，并读取三市场 `0x044d` 代码表；成功后在数据目录写入 `.eltdx_board_cache.json`。

同一天后续调用复用本地资料和名单，不会重复下载或重复读取 `0x044d`。新的一天会重新准备；传入 `refresh=True` 可显式强制重新准备。数据目录可通过 `ELTDX_BOARD_DATA_DIR` 指定，默认使用当前工作目录下的 `downloads`。

板块资料文件自身的修改时间不作为业务日期判断依据，日期以服务端握手日期为准。

## 排序

这两个接口都不负责排序。调用方可以根据 `change_pct`、`amount` 等字段自行排序；如果需要服务端分类排序，应使用 `client.quotes.list_by_category()`（`0x054b`）。
