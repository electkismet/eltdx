# 7709-公司信息内容

## 作用

按 `0x02cf` 返回的目录项，读取某只证券 F10 公司信息的**一段正文**（GBK 文本）。典型用法是先取目录，再按段读取正文。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.company_info.content(code, market, filename, offset, length)` |
| 底层接口 | [`0x02d0`](../COMMANDS_7709.md#cmd-0x02d0) |
| 返回 | `str`（GBK 解码后的正文） |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    sections = client.company_info.category("600000", "sh")
    first = sections[0]
    text = client.company_info.content(
        "600000", "sh", first.filename, first.start, first.length
    )
    print(text)
```

## 怎么选

| 想要的数据 | 调用 | 数据来源 |
| --- | --- | --- |
| 段落正文 | `client.company_info.content(...)` | `0x02d0` 协议通道 |
| 段落目录 | `client.company_info.category(code, market)` | `0x02cf` 协议通道 |
| 在线 F10 资料（HTTP） | `client.f10.fetch(...)` | 7615 TQLEX 接口 |

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 6 位证券代码 |
| `market` | 市场，支持 `sh`、`sz`、`bj`，也支持 `0`、`1`、`2` |
| `filename` | 段落文件名，来自 `CompanyInfoCategory.filename` |
| `offset` | 段落正文起始偏移，来自 `CompanyInfoCategory.start` |
| `length` | 段落正文长度（字节），来自 `CompanyInfoCategory.length` |

## 返回

| 返回值 | 含义 |
| --- | --- |
| `str` | 该段正文，按 GBK 解码 |

## 使用说明

| 项目 | 说明 |
| --- | --- |
| 底层请求 | `0x02d0` 传市场、6 位代码、文件名（80 字节定长）与偏移/长度 |
| 编码 | 正文为 GBK；解码失败字节以替换符呈现 |
| 组合用法 | 先 `category()` 再 `content()`；不要自行猜测偏移与长度 |
| 缓存 | 不缓存；每次调用都会请求主站 |
