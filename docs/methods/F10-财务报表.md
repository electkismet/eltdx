# F10-财务报表

## 作用

查询财务报表。默认 `report_type="zcfzb"` 返回资产负债表。

| 项目 | 内容 |
| --- | --- |
| 调用方法 | `client.f10.finance_report(code, report_type="zcfzb")` |
| 底层 Entry | [`CWServ.tdxf10_gg_cwfx`](../F10_7615.md#entry-cwserv-tdxf10-gg-cwfx) |
| 返回模型 | `F10Response` |

## 示例

```python
from eltdx import F10Client

f10 = F10Client(timeout=3)
balance = f10.finance_report("000034")
income = f10.finance_report("000034", report_type="lyb")
cashflow = f10.finance_report("000034", report_type="xjllb")

print(balance.rows[:3])
print(income.rows[:3])
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `report_type` | 报表类型：`zcfzb` 资产负债表、`lyb` 利润表、`xjllb` 现金流量表；具体列随服务端模板变化 |

## 请求对照

```python
Entry = "CWServ.tdxf10_gg_cwfx"
body = {"Params": ["000034", "zcfzb", ""]}
```

## 字段对照

`report_type="zcfzb"` 返回资产负债表，`report_type="lyb"` 返回利润表，`report_type="xjllb"` 返回现金流量表；`response.rows` 是多期报表行。MCP 会按 `nhytype`（0 通用企业、1 银行、2 券商、3 保险）选择对应模板：

| 类别 | 原生字段 | 中文含义 |
| --- | --- | --- |
| 报告期 | `rq` | 日期 / 报告期 |
| 资产 | `T007` | 货币资金 |
| 资产 | `T008` | 交易性金融资产 |
| 资产 | `T009` | 应收票据 |
| 资产 | `T010` | 应收账款 |
| 资产 | `T020` | 流动资产合计 |
| 资产 | `T039` | 资产总计 |
| 负债 | `T040` | 短期借款 |
| 负债 | `T042` | 应付票据 |
| 负债 | `T043` | 应付账款 |
| 负债 | `T053` | 流动负债合计 |
| 负债 | `T062` | 负债合计 |
| 权益 | `T063` | 实收资本 / 股本 |
| 权益 | `T064` | 资本公积金 |
| 权益 | `T067` | 未分配利润 |
| 权益 | `T077` | 归母权益合计 |
| 权益 | `T071` | 所有者权益合计 |
| 权益 | `T072` | 负债和股东权益合计 |

资产负债表响应里可能出现重复原生列名，例如 `T120`。`response.rows` 会保留为 `T120`、`T120__2`；需要严格按列位置处理时，用 `response.tables[0].row_cells`。

F10 财务报表是资料网关返回的表格数据；7709 的 `finance_batch()` 是行情协议里的基础财务字段，两者字段口径和数据来源不同。

### 行业模板

资产负债表元数据表中的 `nhytype` 决定字段模板：

| `nhytype` | 模板 | “资产总计”字段 | `T039` 含义 |
| --- | --- | --- | --- |
| `0` | 通用企业 | `T039` | 资产总计 |
| `1` | 银行 | `T048` | 固定资产 |
| `2` | 券商 | `T048` | 固定资产 |
| `3` | 保险 | `T048` | 固定资产 |

MCP 返回会按 Entry、报表类型和 `nhytype` 生成 `field_labels`，把服务端新增、重复、尚未确认或不能使用单一标签安全解释的列放入 `unmapped_fields`，并通过 `field_notes` 解释当前结果中需要注意的特殊口径。如果响应没有 `nhytype` 或出现未知值，不会套用通用企业映射；原始 `columns`、`rows` 和 `row_cells` 始终保留。

当前真实样本中，资产负债表和利润表已覆盖四种模板的全部返回列。通用企业现金流量表的 `T063` 已确认是“不涉及现金收支的重大投资和筹资活动”分组标题；它通常为空，但会进入 `field_labels`，同时由 `field_notes` 说明其不承载数值。银行现金流量表的 `T088` 则是动态扩展调节项：历史样本中，农业银行 2017 年中报对应长期资产处置净收益，建设银行 2006 年报对应未实现汇兑损失，无法仅凭行业或报告期选定统一标签。因此 `T088` 继续保留在 `unmapped_fields`，并由 `field_notes` 明确说明歧义。
