# 7709-服务器统计文件解析

## 作用 {#stats-resource}

下载 `zhb.zip` 并解析其中的 `tdxstat.cfg` 与 `tdxstat2.cfg`，返回结构化的统计数据。它是基于 `0x06b9` 的上层便捷调用，不是新的二进制命令。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.resources.read_stats(path="zhb.zip", chunk_size=30000)` |
| 底层接口 | [`0x06b9`](../COMMANDS_7709.md#cmd-0x06b9) |
| 返回模型 | `TdxStatsResource` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    stats = client.resources.read_stats()
    stat, stat2 = stats.row(0, "000001")  # 0=深圳，1=上海
    print(stats.stats_date, stat, stat2)
```

如果已经取得 ZIP bytes，可以只调用纯解析函数：

```python
from eltdx.stats import parse_tdx_stats_archive

stats = parse_tdx_stats_archive(payload, source_path="local://zhb.zip")
```

`tdxstat.cfg` 和 `tdxstat2.cfg` 的字段、列号和格式校验见 [服务器文件读取](7709-服务器文件读取.md#stats-resource)。
