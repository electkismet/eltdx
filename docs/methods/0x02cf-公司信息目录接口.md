# 7709-公司信息目录

## 作用

通过 7709 行情主站的**协议通道**读取某只证券的 F10 公司信息文件目录。主站把一家公司的 F10 资料拆成若干文本段（公司概况、财务报表、股东、经营分析等），`0x02cf` 返回每段的名称、文件名、起始偏移和长度，供 `0x02d0` 按段读取。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.company_info.category(code, market)` |
| 底层接口 | [`0x02cf`](../COMMANDS_7709.md#cmd-0x02cf) |
| 返回 | `list[CompanyInfoCategory]` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    catalogue = client.company_info.category("600000", "sh")
    for section in catalogue:
        print(section.name, section.filename, section.start, section.length)
```

## 怎么选

| 想要的数据 | 调用 | 数据来源 |
| --- | --- | --- |
| 公司信息有哪些段落 | `client.company_info.category(code, market)` | `0x02cf` 协议通道 |
| 某一段的正文 | `client.company_info.content(code, market, filename, offset, length)` | `0x02d0` 协议通道 |
| 在线 F10 资料（HTTP） | `client.f10.fetch(...)` | 7615 TQLEX 接口 |

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 6 位证券代码，如 `600000` |
| `market` | 市场，支持 `sh`、`sz`、`bj`，也支持 `0`、`1`、`2` |

## 返回

| 返回值 | 含义 |
| --- | --- |
| `CompanyInfoCategory.name` | 段落中文名称（GBK 解码） |
| `CompanyInfoCategory.filename` | 段落文件名，传给 `content()` 使用 |
| `CompanyInfoCategory.start` | 段落正文在文件中的起始偏移 |
| `CompanyInfoCategory.length` | 段落正文长度（字节） |

## 使用说明

| 项目 | 说明 |
| --- | --- |
| 底层请求 | `0x02cf` 只传市场与 6 位代码 |
| 与正文的关系 | 目录只描述段落位置，正文由 `0x02d0` 读取，需把 `filename`/`start`/`length` 原样传入 |
| 编码 | 名称与正文均为 GBK |
| 缓存 | 不缓存；每次调用都会请求主站 |
