# F10-市场资讯（资讯频道）

版本说明：PR #31 新增，自 v3.3.2 起可用。

市场资讯（通达信「资讯」页的**要闻速递 / 滚动资讯 / 今日焦点 …** 以及左栏各频道）来自
`page2.tdx.com.cn:7615` 的 TQLEX 接口，是**全市场资讯流**（与个股无关）。本项目通过
`F10Client` 提供的方法封装：

| 场景 | 方法 | Entry | Params |
| --- | --- | --- | --- |
| 资讯首页顶部要闻流 | `market_news(tab, *, page, page_size)` | `CWServ.tdxi_zxxwsy` | `[tab, page, page_size]` |
| 各频道栏目 | `channel_news(channel, *, page, page_size, query1, keyword)` | `CWServ.tdxi_zxxwnews` | `[query1, 频道号, page, page_size, keyword]` |
| 枚举全部频道 | `news_channels()` | —（纯静态） | — |

两个接口的新闻行都在响应 **第 2 个结果集** `result_sets[1].rows`，字段：
`Title`（标题）、`Issue_date`（发布时间）、`Summary`（摘要）、`rec_id`（记录 ID）、
`Info_Src`（来源）、`Url`（原文链接）、`AttachFile`（附件）、`bProc`（研报类标记）。
用 `eltdx.f10.news.extract_news_rows(resp)` 可直接得到 `list[dict]`。

枚举定义见模块 `eltdx.f10.news`：`NewsHomeTab`、`NewsChannel`、`NEWS_CHANNEL_LABELS`、
`NEWS_CHANNEL_GROUPS`、`channel_name()`、`home_tab_name()`。

独立方法文档：[首页要闻](F10-首页要闻.md) · [频道资讯](F10-频道资讯.md) · [资讯频道列表](F10-资讯频道列表.md)。

## 资讯首页要闻流（`NewsHomeTab`，`tdxi_zxxwsy` 的 `query`）

| 枚举 | 值 | 栏目 |
| --- | --- | --- |
| `NewsHomeTab.ROLLING` | 1 | 滚动资讯 |
| `NewsHomeTab.TODAY_FOCUS` | 2 | 今日焦点 |
| `NewsHomeTab.HEADLINES` | 3 | 要闻速递 |
| `NewsHomeTab.POSITIVE` | 4 | 正面消息 |
| `NewsHomeTab.NEGATIVE` | 5 | 负面消息 |
| `NewsHomeTab.ESSENCE` | 6 | 精华集锦 |
| `NewsHomeTab.LATEST_TIPS` | 7 | 最新提示 |
| `NewsHomeTab.INSTITUTION_RESEARCH` | 9 | 机构调研 |

> `query=8`「财经数据」在前端已注释停用。

## 示例

```python
from eltdx.f10 import F10Client, NewsChannel, NewsHomeTab, extract_news_rows

f = F10Client()  # 默认 static.tdx.com.cn:7615；也可 F10Client(base_url="http://page2.tdx.com.cn:7615/TQLEX")

# 要闻速递（首页顶部）
for item in extract_news_rows(f.market_news(NewsHomeTab.HEADLINES, page_size=20)):
    print(item["Issue_date"], item["Title"], "<" + (item["Info_Src"] or "") + ">")

# 财经要闻频道
for item in extract_news_rows(f.channel_news(NewsChannel.FINANCE_HEADLINES, page_size=20)):
    print(item["Issue_date"], item["Title"], item["Url"])

# 枚举全部频道
for cid, name in f.news_channels():
    print(cid, name)
```

底层等价调用（通用入口）：

```python
# tdxi_zxxwsy
f.call("CWServ.tdxi_zxxwsy", body={"Params": ["3", "1", "20"]})          # 要闻速递 第1页20条
# tdxi_zxxwnews
f.call("CWServ.tdxi_zxxwnews", body={"Params": ["1", "201", "1", "20", ""]})  # 财经要闻
```

## 备注

- 2026-10 实测：首页 8 个要闻流全部可取（每页有数据）；全部 84 个频道中仅
  「互联网金融(`1011`)」偶发 0 条（接口 `err=0` 但无数据），其余均正常。
- **产经频道**的「行业要闻/行业公司/行业数据/行业研报」走的是不同的变更接口
  `CWServ.tdxi_zxtzckcontent`（前端 `xwNewsChange`），参数形如
  `["2"|"4"|"6"|"100", "", ""]`，暂未纳入 `NewsChannel`，可先用 `f.call(...)` 直接调用。
- 频道号来源：资讯页脚本 `site/zx/js/zx_xw.js` 的 `firstNav`/`secondNav`
  （各子栏目 `option.query2`），2026-10 服务端页面样本与脚本交叉核对。

## CLI / MCP / HTTP 用法

CLI（`eltdx f10 ...`）：

```bash
eltdx f10 news-channels                              # 列出全部频道号 + 名称
eltdx f10 market-news --tab 3 --page-size 20         # 要闻速递
eltdx f10 channel-news --channel 201 --page-size 20  # 财经要闻
```

MCP 工具（`eltdx-mcp`）：`eltdx_market_news(tab=3, page_size=20)`、
`eltdx_channel_news(channel=201, page_size=20)`、`eltdx_news_channels()`。

HTTP / WebSocket 网关（`eltdx-http`）走通用 RPC，`f10.*` 方法自动暴露：

```json
{"id": 1, "method": "f10.market_news", "params": {"tab": 3, "page_size": 20}}
{"id": 2, "method": "f10.channel_news", "params": {"channel": 201, "page_size": 20}}
{"id": 3, "method": "f10.news_channels", "params": {}}
```
