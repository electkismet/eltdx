# 7709-退市 K 线（日线、不复权）

## 作用

查询退市或历史股票的日线 K 线。该页面对应目前已经抓包并验证的 `0x052B` 协议；当前 SDK 只承诺日线、不复权这一种用法。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.delisted_bars.get(code, ...)` |
| 底层接口 | [`0x052b`](../COMMANDS_7709.md#cmd-0x052b) |
| 返回模型 | `KlineSeries` |
| 单页上限 | `800` 根 |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    page = client.delisted_bars.get("T000038", count=800)
    history = client.delisted_bars.get("T000038", all_pages=True, page_size=800)
```

代码可以传 `T000038` 这类退市代码，也可以传标准化的 `sz000038` / `000038`。SDK 会在请求线上统一发送六位 ASCII 代码（示例中为 `000038`），市场字段由代码前缀或代码规则确定。

`start=0` 表示主站返回的最新一页，`start=800` 表示更早一页。自动分页按服务端实际返回数量递增，只有空页才结束；短页不等同于已经证明历史数据完整。合并后的 `bars` 按日期升序排列，保留服务端返回的全部记录，不自动去重；达到 `max_pages` 仍未遇空页则抛出 `RuntimeError`。

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 退市或历史证券代码 |
| `period` | 当前必须为 `day`（也接受 `1d`、`d`、`daily` 别名） |
| `start` | 分页起点，默认 `0` |
| `count` | 单页条数，范围 `1..800` |
| `adjust` | 当前必须为 `None` 或 `"none"` |
| `include_raw` | 是否保留原始响应 `raw_payload` 和每条 `record_hex`，默认 `False` |
| `all_pages` | 是否自动分页到空页 |
| `page_size` | 自动分页的每页条数，范围 `1..800` |
| `max_pages` | 自动分页的最大页数，默认 `200`；`None` 表示不设页数上限，但 `start` 仍限于协议的 `0..65535` |

## 返回字段

返回现有 `KlineSeries` / `KlineBar` 模型。`period_name="day"`、`adjust_mode="none"` 是当前接口固定语义；共享模型中的 `period_raw` / `period_param_raw` 等周期、复权字段仅用于兼容现有模型，不表示本请求在线上携带了周期或复权选择参数。

| 字段 | 含义 |
| --- | --- |
| `time` | 协议只含日期，SDK 映射为上海时区当天 `00:00`，不代表成交时间 |
| `open` / `close` / `high` / `low` | 不复权开高低收价格，单位元 |
| `volume_raw` / `volume_wire_value` | 解码后的股数；`volume_raw` 不是普通 K 线的紧凑浮点原始码 |
| `volume_lots` | 手数，股数除以 `100` |
| `amount` | 成交额，单位元 |
| `last_close_price_milli` | 同页前一条记录的收盘毫厘价；每页首条为 `None` |
| `record_hex` | `include_raw=True` 时保留完整单条记录，包括末尾四字节 |
| `raw_payload` | `include_raw=True` 时保留响应正文；自动分页合并时仅保留第一张响应的正文 |

默认 `include_raw=False` 时 `record_hex=""`、`raw_payload=b""`。若需要逐页原文，请使用 `start/count` 手动分页。

## 当前协议边界

- 已验证：退市/历史股票、日线、不复权。
- 未承诺：周线、月线、分钟线或其他周期。
- 未承诺：前复权、后复权、定点复权。
- 成交量按协议样本解释为股数，不套用普通 `0x052D` K 线的手数换算。
- 每条记录末尾的 4 字节已保留，但完整业务含义仍待进一步验证。
- 不同主站的历史覆盖范围可能不同；短页、空页和节点差异不能单独证明全历史完整性。

普通证券的多周期和服务端复权仍使用 [`client.bars.get()`](7709-K线周期线.md)，不要用它的字段口径反推本接口。
