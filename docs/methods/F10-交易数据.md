# F10-交易数据

## 作用

查询交易数据页面：近期融资融券、近 6 个月融资融券、大宗交易、龙虎榜、沪深股通、跌停分析、涨停分析、可转债、主力盘口、研报席位和科创板标记。11 个分区由 `client.f10.trading_report()` 的 `section` 参数分派，底层是 `CWServ.tdxf10_gg_jyds`，只有 `margin_history` 走区间通道 `CWServ.tdxf10_gg_sj`。

资金流向本身由 `client.money_flow.history()` 提供，本方法不重复：

```python
client.money_flow.history("688004", days=60)   # 7615 CWServ.tdxf10_gg_sj，列语义见资金流向文档
```

| 项目 | 内容 |
| --- | --- |
| 调用方法 | `client.f10.trading_report(code, section="margin", *, arg="", date=None, page=1, page_size=20)` |
| 底层 Entry | [`CWServ.tdxf10_gg_jyds`](../F10_7615.md#entry-cwserv-tdxf10-gg-jyds)；`margin_history` 走 [`CWServ.tdxf10_gg_sj`](../F10_7615.md#entry-cwserv-tdxf10-gg-sj) |
| 返回模型 | `F10Response` |

## 分区（section）

| section | 中文分区 | 需要额外参数 |
| --- | --- | --- |
| `margin` | 近期融资融券 | — |
| `margin_history` | 近 6 个月融资融券 | 改走 `CWServ.tdxf10_gg_sj` |
| `block_trades` | 大宗交易 | — |
| `dragon_board` | 龙虎榜 | `arg` 默认 `2` |
| `northbound` | 沪深股通 | — |
| `limit_down` | 跌停分析 | — |
| `limit_up` | 涨停分析 | — |
| `bonds` | 可转债 | — |
| `main_force` | 主力盘口 | — |
| `reports` | 研报/席位 | — |
| `kcb` | 科创板标记 | — |

`date` 目前没有被任何分区使用，保留它只是为了让签名与其它报表方法一致；`page` / `page_size` 只对分页类分区有意义。

## 示例

```python
from eltdx import F10Client

f10 = F10Client(timeout=3)

margin = f10.trading_report("688004", "margin")
history = f10.trading_report("688004", "margin_history")
limit_up = f10.trading_report("688004", "limit_up")

print(margin.rows[:3])
print(history.rows[:3])
print(limit_up.rows[0])
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `section` | 分区，见上表，默认 `margin` |
| `arg` | 分区附加参数；目前只有 `dragon_board` 使用（默认 `2`） |
| `date` | 保留参数，当前没有分区使用 |
| `page` / `page_size` | 页码 / 每页条数，默认 `1` / `20` |

## 请求对照

```python
Entry = "CWServ.tdxf10_gg_jyds"
# margin        {"Params": ["688004", "rzrq",     ""]}
# block_trades  {"Params": ["688004", "dzjy",     ""]}
# dragon_board  {"Params": ["688004", "lgt",      "2"]}
# northbound    {"Params": ["688004", "islgt",    ""]}
# limit_down    {"Params": ["688004", "dtfx",     ""]}
# limit_up      {"Params": ["688004", "ztfx",     ""]}
# bonds         {"Params": ["688004", "zrq",      ""]}
# main_force    {"Params": ["688004", "zlpskcj",  ""]}
# reports       {"Params": ["688004", "yxsbxx",   ""]}
# kcb           {"Params": ["688004", "checkkcb", ""]}

Entry = "CWServ.tdxf10_gg_sj"
# margin_history {"Params": ["rzrq_sj", "688004", "0", "688004"]}
```

`margin_history` 的第 3 个 `Params` 元素是服务端窗口参数（`"0"` 表示服务端默认窗口，实测约 4 个月 122 行），第 4 个元素是代码。

## 字段对照

| section | 常用字段 |
| --- | --- |
| `margin` | `T001` 交易日、`T003` 融资余额、`T004` 融资买入额、`T005` 融券金额、`ClosePrice` 收盘价 |
| `margin_history` | `N001` 交易日、`N002` 代码、`N003` 名称、`N004` 融资余额、`N008` 融券金额、`N009` 占流通市值%、`N013` 上市日期 |
| `block_trades` | `T003` 日期、`T004` 成交价、`T005` 成交量、`T006` 成交额、`yjl` 溢价率 |
| `dragon_board` | `rq` 上榜日、`T006`/`T007` 榜单指标 |
| `northbound` | `T001` 持股比例 / 数量序列 |
| `limit_down`、`limit_up` | `currq`、`lx` 类型、`sT002` 日期、`T011` 时间、`fdje` 封单金额、`zt` 题材、`yy` 原因、`N005` 金额 |
| `bonds` | `N001`～`N008` 可转债要素、`chl` 纯债溢价率 |
| `main_force` | `N001`～`N008` 主力盘口指标 |
| `reports` | `N001`～`N006` 席位信息 |
| `kcb` | `sc` 市场（`1` 表示科创板标的） |

`margin`、`dragon_board`、`main_force` 等分区会返回多张表，全部表可用：

```python
for table in response.tables:
    print(table.key, table.columns, table.rows[:2])
```

适合做两融跟踪、龙虎榜 / 涨停复盘和交易结构分析。
