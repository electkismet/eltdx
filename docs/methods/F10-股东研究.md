# F10-股东研究

## 作用

查询股东研究相关数据：股东人数、同行业股东人数增减量排名、控股股东与实际控制人、十大流通股东、十大股东、十大债券持有人、重要股东持股变动、机构持股汇总与分类、机构持仓明细，以及股东增减持计划。这些页面是同一套接口的不同分区，由 `client.f10.shareholders()` 的 `section` 参数分派。

| 项目 | 内容 |
| --- | --- |
| 调用方法 | `client.f10.shareholders(code, section="count", *, report_date=None, kind="000", filter1="", filter2="", page=1, page_size=20)` |
| 底层 Entry | [`CWServ.tdxf10_gg_gdyj`](../F10_7615.md#entry-cwserv-tdxf10-gg-gdyj)；`institution_holdings` 走 [`CWServ.tdxf10_gg_gdyj_jgcgmx`](../F10_7615.md#entry-cwserv-tdxf10-gg-gdyj-jgcgmx) |
| 返回模型 | `F10Response` |

## 分区（section）

| section | 中文分区 | 需要额外参数 |
| --- | --- | --- |
| `count` | 股东人数与股价比较 | — |
| `ranking` | 同行业股东人数增减量排名 | — |
| `controller` | 控股股东与实际控制人 | — |
| `top_circulating` | 十大流通股东 | — |
| `top` | 十大股东（按报告期） | — |
| `bonds` | 十大债券持有人 | — |
| `changes` | 重要股东持股变动 | — |
| `institutions` | 机构持股汇总 | — |
| `institution_types` | 机构持股分类汇总 | `filter2` 取报告期 |
| `institution_holdings` | 机构持仓明细 | 改走 `CWServ.tdxf10_gg_gdyj_jgcgmx`，用 `kind` 与 `report_date` |
| `plan` | 股东增减持计划 | — |

`plan` 就是原 `client.f10.shareholder_change_plans()` 的分区，字段与 [F10-股东增减持.md](F10-股东增减持.md) 完全一致。

## 示例

```python
from eltdx import F10Client

f10 = F10Client(timeout=3)

count = f10.shareholders("688004", "count")
controller = f10.shareholders("688004", "controller")
holdings = f10.shareholders("688004", "institution_holdings", kind="000", report_date="20260630")

print(count.rows[:3])
print(controller.rows)
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `section` | 分区，见上表，默认 `count` |
| `report_date` | 报告期 `YYYYMMDD`；`institution_holdings` 与 `institution_types` 使用 |
| `kind` | 机构类型，仅 `institution_holdings` 使用，默认 `000` |
| `filter1` | 服务端筛选参数，默认空 |
| `filter2` | 服务端筛选参数；`institution_types` 用它传报告期 |
| `page` / `page_size` | 页码 / 每页条数，默认 `1` / `20` |

## 请求对照

```python
Entry = "CWServ.tdxf10_gg_gdyj"

# controller          {"Params": ["688004", "kggd",         "",  "",         "1", "1", "20"]}
# top_circulating     {"Params": ["688004", "ltgd",         "",  "",         "1", "1", "20"]}
# top                 {"Params": ["688004", "sdgdbgq",      "",  "",         "1", "1", "20"]}
# bonds               {"Params": ["688004", "sdzqcyr",      "",  "",         "1", "1", "20"]}
# changes             {"Params": ["688004", "cgbd",         "",  "",         "1", "1", "20"]}
# institutions        {"Params": ["688004", "jgcg",         "",  "",         "1", "1", "20"]}
# institution_types   {"Params": ["688004", "jgcgz",        "",  "20260630", "1", "1", "20"]}
```

第 3、4 个 `Params` 元素对应 `filter1` / `filter2`；`institution_holdings` 的第 4 个元素固定为 `"99"`。

## 返回示例

`section="count"`（股东人数与股价比较，实测 26 行）：

```python

# {
#     "T002": "2026-06-30",   # 报告期
#     "T003": 5465,           # 股东人数（户）
#     "T004": 14654.7118,     # 户均持股数（股）
#     "T005": -9.1136,        # 股东人数环比%
#     "T006": 10.0274,        # 户均持股数环比%
#     "T007": 18.2,           # 户均持股市值（万元）
#     "T012": -548,           # 股东人数变动（户）
# }
```

```python
f10.shareholders("688004", "controller").rows[0]
```

其它分区的常用字段：

| section | 常用字段 |
| --- | --- |
| `ranking` | `zqdm` 代码、`zqjc` 名称、`sc` 市场、`T003` 股东人数、`T005` 增减率 |
| `top_circulating` | `rq` 报告期、`T004` 总股本、`T019` 流通股本 |
| `top` | `rq` 报告期、`gd` 股东名称、`cgs` 持股数、`bl` 持股比例%、`xz` 股份性质、`lb` 股东类别、`stp` 排名 |
| `bonds` | `zqcode`/`zqname` 债券代码与名称、`T004` 持有数、`T005` 占比% |
| `changes` | `qs`/`jz` 变动起止日、`T005` 股东名称、`T006` 成交均价、`T007` 变动数量、`T008` 变动后持股数、`T009` 变动方式、`T011` 身份 |
| `institutions` | `T002` 报告期、`T003` 机构家数、`T005` 持股总数、`T006` 变动股数、`T007` 持股市值、`T008` 持股占比%、`T010` 市值占比%、`T014` 户均持股 |
| `institution_types` | `T003` 机构类型、`T005` 持股数、`T008` 占比%、`T012`/`sT012` 变动 |
| `institution_holdings` | 明细行，同样按 `N00x` 原生列名返回，与 `count` 无共享列 |

`response.rows` 默认取第一张表；有些分区（如 `top`、`ranking`）会附带的元信息在 `response.tables[1:]` 中，可用下面的方式查看所有表：

```python
for table in response.tables:
    print(table.key, table.columns, table.rows[:2])
```

适合做股东结构、机构动向和增减持计划跟踪。
