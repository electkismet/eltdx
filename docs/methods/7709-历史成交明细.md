# 7709-历史成交明细

## 作用

分页查询指定日期的成交明细增强数据。返回记录中可能包含普通成交、集合竞价过程快照和 09:25 正式撮合，解析器通过 `event_kind` 区分语义。需要只取其中一种记录时，请使用对应的筛选接口文档。

| 项目 | 内容 |
| --- | --- |
| 主要调用 · 单页 | `client.trades.history(code, date, ...)` |
| 完整分页 | `client.trades.all_history(code, date)` |
| 底层接口 | [`0x0fc6`](../COMMANDS_7709.md#cmd-0x0fc6) |
| 返回模型 | `TradePage` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    page = client.trades.history("sz000001", "2026-05-20", start=0, count=1800)
    all_ticks = client.trades.all_history("sz000001", "2026-05-20")

print(page.ticks[:3])
print(len(all_ticks.ticks))
```

历史查询必须使用 `client.trades.history(code, date)`；`client.trades.today(code)` 固定调用当日 `0x0fc5`，协议请求本身不传交易日期。

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `trading_date` / `date` | 交易日，支持 `YYYY-MM-DD`、`YYYYMMDD`、`date` |
| `start` | 起始位置，从 `0` 开始 |
| `count` | 本页条数，便捷方法默认 `1800`，服务端单页上限也是 `1800` |
| `include_raw` | 是否保留原始 payload |

## 解析字段

| `TradePage` 字段 | 含义 |
| --- | --- |
| `exchange` / `market_id` / `code` / `full_code` | 市场和代码 |
| `start` / `request_count` | 请求起点 / 请求条数 |
| `trading_date` | 成交日期 |
| `price_base_raw_f32` | 价格基数原始字段 |
| `ticks` | 原始记录，包含 `trade`、`auction_snapshot`、`opening_match` |
| `auction_snapshots` | 从本页筛出的 `status=8` 集合竞价快照 |
| `opening_matches` | 从本页筛出的 09:25 正式撮合记录 |
| `count` | 混合记录条数 |
| `has_more` | 单页结果中 `count >= request_count` 时为 `True`，表示可能还有下一页 |
| `raw_payload` | 原始 payload |

| `TradeTick` 字段 | 含义 |
| --- | --- |
| `index` | 本页内序号 |
| `absolute_index` | 全局序号 |
| `time_minutes` | 当日分钟数 |
| `time_label` / `trade_datetime` | 成交时间 |
| `price` / `price_milli` | 成交价 / 毫厘价 |
| `volume` | 原始数量字段，普通成交/正式撮合时是成交量；`status=8` 时是虚拟匹配量 |
| `order_count` | 原始笔数字段；`status=8` 时是带符号未匹配量 |
| `event_kind` | `trade`、`auction_snapshot` 或 `opening_match` |
| `is_auction_snapshot` / `is_opening_match` / `is_trade` | 事件类型判断属性 |
| `auction_matched_volume` | 仅竞价快照有值的虚拟匹配量 |
| `auction_unmatched_signed_volume` / `auction_unmatched_volume` | 仅竞价快照有值的带符号 / 绝对值未匹配量 |
| `status_raw` | 方向 / 状态原始值 |
| `side` | 方向，`buy`、`sell`、`neutral` 或状态名 |
| `price_delta_raw` | 成交价差分原始值 |
| `price_acc_raw` | 成交价差分累计值 |
| `reserved_zero` | 历史成交明细尾部保留字段 |
| `record_hex` | 单条原始十六进制 |
| `trade_amount_yuan` | 按原始数量计算的金额；竞价快照仅作估算，不代表实际成交金额 |

## 翻页规则

| 项目 | 说明 |
| --- | --- |
| 起始页 | `start=0` |
| 下一页 | `start += 当前页实际返回数量` |
| 单页结果可能还有数据 | `page.has_more` 为 `True` |
| 拉某日全部成交明细 | 用 `client.trades.all_history(code, date)` |

`status_raw == 8` 的记录不是实际成交；时间为 `09:25` 且不是 `status=8` 的记录归类为 `opening_match`，其余记录归类为 `trade`。

需要只取集合竞价记录或 09:25 正式撮合时，分别使用《历史成交明细竞价记录》和《历史 09:25 正式撮合》中的入口。
