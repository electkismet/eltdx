# F10-公司资讯研报

## 作用

查询公司资讯，默认 `section="gsyj"` 返回研报列表，也可以按服务端分区查询监管措施、财报点评（`section="finance_review"`，底层 Entry 改用 `CWServ.tdxf10_gg_cwfx_cbdp`）等内容。

| 项目 | 内容 |
| --- | --- |
| 调用方法 | `client.f10.company_news(code, section="gsyj", page=1, page_size=20)` |
| 底层 Entry | [`CWServ.tdxf10_gg_gszx`](../F10_7615.md#entry-cwserv-tdxf10-gg-gszx)（`finance_review` 走 [`CWServ.tdxf10_gg_cwfx_cbdp`](../F10_7615.md#entry-cwserv-tdxf10-gg-cwfx-cbdp)） |
| 返回模型 | `F10Response` |

## 示例

```python
from eltdx import F10Client

f10 = F10Client(timeout=3)
reports = f10.company_news("000034")
supervision = f10.company_news("000034", section="jgcs")

print(reports.rows[:5])
print(supervision.rows[:5])
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `section` | 分区；`gsyj` 常用于研报，`jgcs` 常用于监管措施，`finance_review` 为财报点评（切换 Entry，只使用 `page`） |
| `keyword` | 关键词 |
| `rating` | 评级筛选 |
| `page` / `page_size` | 分页参数 |

## 请求对照

```python
Entry = "CWServ.tdxf10_gg_gszx"
body = {"Params": ["000034", "gsyj", "", "0", "1", "20"]}

# section="finance_review" 切换 Entry，Params 只保留代码与页码
Entry = "CWServ.tdxf10_gg_cwfx_cbdp"
body = {"Params": ["000034", "1"]}
```

## 返回示例

```python
response.rows[0]
# {
#     "T004": "买入",
#     "T009": "研究员姓名",
#     "T012": "20260505",
#     "T011": 1629068,
#     "T039": "研报标题",
#     "nflag": "0",
#     "ybdz": "研报地址或附件标识"
# }
```

## 字段对照

| `section` | 含义 |
| --- | --- |
| `gsyj` | 公司研究 / 研报 |
| `jgcs` | 监管措施 / 处罚函件 |
| `finance_review` | 财报点评（Entry `CWServ.tdxf10_gg_cwfx_cbdp`） |

`gsyj` 研报常用字段：

| 原生字段 | 中文含义 |
| --- | --- |
| `T004` | 评级类别 |
| `T009` | 研究员 |
| `T012` | 撰写日期 |
| `T011` | 研报详情 ID |
| `T039` | 研报标题 |
| `nflag` | 服务端标记 |
| `ybdz` | 研报地址 / 附件标识 |

`jgcs` 监管措施常用字段：`N001` 处罚公布日期、`N002` 处罚对象、`N003` 监管措施、`N004` 函件内容、`N005` 链接。

`finance_review` 财报点评常用字段：`bt` 标题、`jg` 机构、`rq` 日期、`rec_id` 详情 ID（交给 `client.f10.detail("cwfx", rec_id)` 读正文）。

`rating` 评级筛选常用取值：`0` 全部、`5` 买入、`4` 增持、`3` 中性、`2` 减持、`1` 卖出。

## `client.f10.digest()`

### 作用

个股 F10「最新提示」页：默认 `section="tips"` 返回最新提示，其余分区返回公司概要、公司大事、公司新闻、公司公告、公司研报、路演互动和投资者互动。前 7 个分区共用一个 Entry，靠 `Params[1]` 的子命令区分；`interaction` 换用投资者互动专用 Entry。

| 项目 | 内容 |
| --- | --- |
| 调用方法 | `client.f10.digest(code, section="tips", *, page=1, page_size=20)` |
| 底层 Entry | [`CWServ.tdxf10_gg_zxts`](../F10_7615.md#entry-cwserv-tdxf10-gg-zxts)（`interaction` 走 [`CWServ.tdxf10_gg_zxtstzzhd`](../F10_7615.md#entry-cwserv-tdxf10-gg-zxtstzzhd)） |
| 返回模型 | `F10Response` |

### 示例

```python
from eltdx import F10Client

f10 = F10Client(timeout=3)
tips = f10.digest("688004")
events = f10.digest("688004", section="events")
interaction = f10.digest("688004", section="interaction", page_size=5)

print(tips.rows[:3])
print(events.rows[:3])
print(interaction.rows[:3])
```

### 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `section` | 分区，见下表，默认 `tips`；未知取值抛 `ValueError` 并列出全部合法取值 |
| `page` | 当前没有分区使用，仅为与其它列表方法保持签名一致 |
| `page_size` | 仅 `interaction` 使用，其它分区由服务端返回全部记录 |

### 请求对照

```python
Entry = "CWServ.tdxf10_gg_zxts"
# tips          {"Params": ["688004", "zxts", ""]}
# profile       {"Params": ["688004", "gsgy", ""]}
# events        {"Params": ["688004", "gsds", ""]}
# news          {"Params": ["688004", "gsxw", ""]}
# announcements {"Params": ["688004", "gsgg", ""]}
# reports       {"Params": ["688004", "gsyj", ""]}
# roadshows     {"Params": ["688004", "lyhd", ""]}

Entry = "CWServ.tdxf10_gg_zxtstzzhd"
# interaction   {"Params": ["688004", "1", "1", "20"]}
```

### 字段对照

| `section` | 中文分区 | 子命令 | 实测（688004） |
| --- | --- | --- | --- |
| `tips` | 最新提示 | `zxts` | 1 行 |
| `profile` | 公司概要 | `gsgy` | 1 行（`gsdw`） |
| `events` | 公司大事 | `gsds` | 13 行 |
| `news` | 公司新闻 | `gsxw` | 10 行 |
| `announcements` | 公司公告 | `gsgg` | 10 行 |
| `reports` | 公司研报 | `gsyj` | 0 行（该股确实为空） |
| `roadshows` | 路演互动 | `lyhd` | 6 行 |
| `interaction` | 投资者互动 | 无（专用 Entry） | 5 行 |

新闻、公告、研报和投资者互动的行里都带记录 ID，可直接交给 `client.f10.detail(detail_type, record_id)` 读正文；公告与新闻也可以对照 `client.f10.announcements()` / `client.f10.news()` 的缓存列表。
