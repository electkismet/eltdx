# 7709-集合竞价明细

## 作用

查询主站当前保存的集合竞价过程快照，包括价格、虚拟匹配量、未匹配量等。它是专用的竞价快照接口，不是逐笔成交接口。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.auctions.series(code)` |
| 底层接口 | [`0x056a`](../COMMANDS_7709.md#cmd-0x056a) |
| 返回模型 | `AuctionSeries` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    series = client.auctions.series("sz000001")
    for point in series.points:
        print(point.time_label, point.price, point.matched_volume)
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `include_raw` | 是否保留原始 payload |

这个接口请求参数里没有交易日期字段，返回主站当前保存的数据；凌晨、周末或节假日可能仍是最近交易日数据。上午记录通常覆盖 `09:15:00` 到 `09:24:57`，部分市场可能到 `09:24:59` 或 `09:25:00`；尾盘还可能出现 `14:57` 到 `15:00`。即使出现 `09:25:00`，它仍然是竞价快照，不能当作正式成交笔数。历史某天的 09:25 正式撮合应使用 [7709-历史成交明细.md](7709-历史成交明细.md) 扫描 `opening_match`。

## 解析字段

| `AuctionSeries` 字段 | 含义 |
| --- | --- |
| `exchange` / `market_id` / `code` / `full_code` | 市场和代码 |
| `mode_or_selector_raw` | 模式 / 选择器原始值 |
| `start_raw` | 起始参数原始值 |
| `limit_or_count_raw` | 数量参数原始值 |
| `points` | 竞价明细记录 |
| `count` | 记录数 |
| `raw_payload` | 原始 payload |

| `AuctionPoint` 字段 | 含义 |
| --- | --- |
| `index` | 序号 |
| `minute_of_day_raw` | 当日分钟原始值 |
| `second_raw` | 秒原始值 |
| `time_label` | 时间 |
| `time_seconds` | 当日秒数 |
| `price` / `price_milli` | 竞价价格 / 毫厘价 |
| `matched_volume` | 虚拟匹配量，单位手，不代表已经发生的逐笔成交 |
| `unmatched_signed_raw` | 未匹配量带符号原始值 |
| `unmatched_volume` | 未匹配量，单位手 |
| `unmatched_direction_raw` | 未匹配方向原始值 |
| `reserved_zero_0e` | 保留字段 |
| `record_hex` | 单条原始十六进制 |
| `matched_amount_estimated` | 估算成交额，`price * matched_volume * 100` |

## 和成交明细接口的区别

| 方法 | 数据来源 | 适合场景 |
| --- | --- | --- |
| `client.auctions.series()` | `0x056a` 集合竞价快照 | 看竞价阶段价格、虚拟匹配量、未匹配量的过程 |
| `client.trades.today()` / `all_today()` | `0x0fc5` 当日成交明细 | 看主站当前保存的逐笔记录，并读取其中的 `status=8` 竞价快照和 `09:25` 正式撮合 |
| `client.trades.history()` / `all_history()` | `0x0fc6` 历史成交明细 | 看指定日期逐笔记录，并读取其中的 `status=8` 竞价快照和 `09:25` 正式撮合 |
| `client.trades.auction_today()` / `auction_history()` | `0x0fc5` / `0x0fc6` 成交明细 | 分别读取当日 / 历史 `status=8` 集合竞价记录 |
| `client.trades.opening_match_today()` / `opening_match_history()` | `0x0fc5` / `0x0fc6` 成交明细 | 分别读取当日 / 历史 `event_kind="opening_match"` 的 09:25 正式撮合 |
