# 7709-全量K线分页

## 作用

自动按页拉取 K 线并合并，直到服务端返回空页。适合补历史日线、分钟线或长期周期数据。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.bars.all(code, ...)` |
| | 底层接口 | [`0x052d`](../COMMANDS_7709.md#cmd-0x052d) |
| 返回模型 | `KlineSeries` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    series = client.bars.all("sz000001", period="day")
    qfq = client.bars.all("sz000001", period="day", adjust="qfq")
```

最多拉 20 页：

```python
series = client.bars.all("sz000001", period="day", page_size=800, max_pages=20)
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `period` | 周期，和 `client.bars.get()` 一致 |
| `adjust` | 复权模式 |
| `anchor_date` | 定点复权日期 |
| `kind` | `stock` 或 `index` |
| `page_size` | 每页条数，服务端上限 `800` |
| `max_pages` | 最多拉几页；防止异常情况下无限循环 |
| `include_raw` | 是否保留原始 payload |

## 解析字段

返回字段同 [7709-K线周期线.md](7709-K线周期线.md)。区别是 `bars` 已经合并多页结果，`request_count` 会被更新为最终合并后的条数。

## 翻页规则

| 项目 | 说明 |
| --- | --- |
| 起始页 | `start=0` |
| 下一页 | `start += 当前页实际返回数量` |
| 停止条件 | 主站返回空页 |
| 安全阈值 | `max_pages` 不为 `None` 时，超过页数直接抛错 |

短页不代表数据已经结束；SDK 会按本页实际返回数量推进 `start`，继续查询到空页。全量方法每次按请求读取结果。K 线属于可能频繁变化的数据，尤其是当日分钟线和当日日 K，适合由调用方按自己的策略缓存。
