# F10-行业分析

## 作用

查询行业分析页面：同业对比、同业分红排名、同业规模、同业估值、行业新闻、行业研报、市场份额和行业汇总。前 8 个分区由 `client.f10.industry_analysis()` 的 `section` 参数分派，底层只有 `CWServ.tdxf10_gg_hyfx` 一个 Entry，靠 `Params[0]` 的子命令区分；另两个分区 `comparable`（可比公司列表）与 `comparable_profile`（本公司在本页的资料）改用 `CWServ.tdxf10_gg_kbgs`，`Params` 为 `[子命令, code]`。

| 项目 | 内容 |
| --- | --- |
| 调用方法 | `client.f10.industry_analysis(code, section="peers", *, arg="")` |
| 底层 Entry | [`CWServ.tdxf10_gg_hyfx`](../F10_7615.md#entry-cwserv-tdxf10-gg-hyfx) |
| 返回模型 | `F10Response` |

## 分区（section）

| section | 中文分区 | 子命令 | `arg` 默认值 |
| --- | --- | --- | --- |
| `peers` | 同业对比 | `cwgz` | `000` |
| `dividend_rank` | 同业分红排名 | `fhrzb` | `100` |
| `scale` | 同业规模 | `gsgm` | `000` |
| `valuation` | 同业估值 | `gzsp` | `011` |
| `news` | 行业新闻 | `hyxw` | 空串 |
| `reports` | 行业研报 | `hyyb` | 空串 |
| `market_share` | 市场份额 | `scbx` | `000` |
| `summary` | 行业汇总 | `tot` | 空串 |
| `comparable` | 可比公司列表（Entry 改用 `CWServ.tdxf10_gg_kbgs`） | `1` | 不使用 |
| `comparable_profile` | 可比公司资料（本公司，同一 Entry） | `0` | 不使用 |

`arg` 为空字符串时使用上表的默认值；显式传入会覆盖默认值。

## 示例

```python
from eltdx import F10Client

f10 = F10Client(timeout=3)

peers = f10.industry_analysis("688004", "peers")
valuation = f10.industry_analysis("688004", "valuation", arg="011")
summary = f10.industry_analysis("688004", "summary")

print(peers.rows[:5])
print(valuation.rows[:3])
print(summary.rows[0])
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `section` | 分区，见上表，默认 `peers` |
| `arg` | 分区附加参数；空字符串时用该分区的默认值 |

## 请求对照

**`Params` 顺序是「子命令在前、代码在后、附加参数最后」**：

```python
Entry = "CWServ.tdxf10_gg_hyfx"
# peers         {"Params": ["cwgz",  "688004", "000"]}
# dividend_rank {"Params": ["fhrzb", "688004", "100"]}
# scale         {"Params": ["gsgm",  "688004", "000"]}
# valuation     {"Params": ["gzsp",  "688004", "011"]}
# news          {"Params": ["hyxw",  "688004", ""]}
# reports       {"Params": ["hyyb",  "688004", ""]}
# market_share  {"Params": ["scbx",  "688004", "000"]}
# summary       {"Params": ["tot",   "688004", ""]}
```

`comparable` / `comparable_profile` 的子命令在前、代码在后，但换用另一个 Entry：

```python
Entry = "CWServ.tdxf10_gg_kbgs"
# comparable        {"Params": ["1", "688004"]}
# comparable_profile {"Params": ["0", "688004"]}
```

注意这与 `client.f10.shareholders()` 等「代码在前」的 Entry 相反，写自定义调用时不要照抄别的分区。

## 返回示例

`section="peers"`（同业对比，实测 20 行）：

```python
f10.industry_analysis("688004", "peers").rows[0]
# {
#     "pm": 1,            # 排名
#     "zqdm": "688692",   # 同业代码
#     "zqjc": "达梦数据",  # 同业名称
#     "sc": 1,            # 市场
#     "T056": 1.95,       # 财务指标
#     "T059": 34.2257,
#     "T062": 0.0399,
#     "T067": 30.29,
#     "T118": 7.99,
# }
```

`section="summary"`（行业汇总，实测 1 行）：

```python
f10.industry_analysis("688004", "summary").rows[0]
# {"cnt": 232, "bkname": "计算机-软件服务", "jzrq": 20261012}
```

`section="news"`（行业新闻，实测 87 行）与 `section="reports"`（行业研报，实测 22 行）：

```python
f10.industry_analysis("688004", "news").rows[0]
# {"issue": "09:06", "Title": "财联社10月13日电，…", "rec_id": 22074829, "nflag": "1"}

f10.industry_analysis("688004", "reports").rows[0]
# {"issue": "09-24", "Title": "软件与服务行业…", "rec_id": 3414137, "nflag": "0", "ybdz": "172CF691…"}
```

新闻 / 研报的 `rec_id` 可以直接交给 `client.f10.detail("xw", rec_id)` 读正文。

## 字段对照

| section | 常用字段 |
| --- | --- |
| `peers` | `pm` 排名、`zqdm`/`zqjc` 代码与名称、`sc` 市场，`T056`/`T059`/`T062`/`T067`/`T118` 为同业对比指标 |
| `dividend_rank` | `pm` 排名、`ssfh` 每股分红、`fhje` 分红金额、`sfmzje` 首发募资、`pgmzje` 配股募资、`fhrzb` 分红融资比 |
| `scale` | `zqdm`/`zqjc`、`T013` 总市值、`T012` 流通市值、`T010`/`T011` 总股本与流通股本、`T009` 营业收入、`T006` 指标值 |
| `valuation` | `T006` 指标值、`T019`/`sT019` 市盈率、`T018` 市净率、`T017` 市销率、`T020`/`T021` 分位 |
| `news` | `issue` 时间、`Title` 标题、`rec_id` 详情 ID、`nflag` 标记 |
| `reports` | `issue` 日期、`Title` 标题、`rec_id` 详情 ID、`ybdz` 研报地址标记 |
| `market_share` | `zqdm`/`zqjc`、`T022`～`T027` 市场表现指标 |
| `summary` | `cnt` 同业家数、`bkname` 行业名称、`jzrq` 数据日期 |
| `comparable` | `t003` 可比公司代码、`T004` 公司名称（688004 实测 11 行，首行 `300628` 亿联网络） |
| `comparable_profile` | 本公司在本页的资料（688004 实测 1 行） |

多数分区会返回多张表（主表 + 口径说明），需要全部表时用：

```python
for table in response.tables:
    print(table.key, table.columns, table.rows[:2])
```

适合做同业估值比较、行业地位和行业资讯跟踪。
