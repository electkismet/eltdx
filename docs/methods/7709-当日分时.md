# 7709-当日分时

## 作用

查询主站当前保存的分时序列，返回每分钟价格、成交量和均价等字段。盘中会持续更新；凌晨、周末或节假日可能返回最近交易日数据。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.minutes.today(code)` |
| 底层接口 | [`0x0537`](../COMMANDS_7709.md#cmd-0x0537) |
| 返回模型 | `MinuteSeries` |

调用 `client.minutes.today(code)` 时不传日期，走的就是这个当日分时接口。这里的“当日”指主站当前保存的数据，凌晨、周末或节假日可能仍是最近交易日；原始请求和响应都不带交易日期。

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    series = client.minutes.today("sz000001")
    print(series.count, series.volume_sum)
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `include_raw` | 是否保留原始 payload，默认 `False` |

## 解析字段

| `MinuteSeries` 字段 | 含义 |
| --- | --- |
| `exchange` | 市场前缀，`sz` / `sh` / `bj` |
| `market_id` | 市场编号，`0=sz`、`1=sh`、`2=bj` |
| `code` | 六位代码 |
| `full_code` | 完整代码 |
| `trading_date` | 当日分时响应本身不带日期，所以保持为空 |
| `reserved_zero` | 响应头保留字段 |
| `prev_close` / `open_price` | 昨收 / 今开；当日分时协议通常不提供，可能为 `None` |
| `date_selector_raw` | 日期选择器原始值；当日接口通常为 `None` |
| `points` | 分时点列表 |
| `count` | 分时点数量 |
| `volume_sum` | 分时成交量合计 |
| `raw_payload` | 原始 payload |

| `MinutePoint` 字段 | 含义 |
| --- | --- |
| `index` | 分时序号 |
| `time_label` | 时间文本，例如 `09:30`、`10:01` |
| `time` | 带日期的时间；当日分时通常为空 |
| `price` / `price_milli` | 当前价格 / 千分价格单位 |
| `avg_price` | 均价 |
| `volume` | 该分钟成交量，单位手 |
| `price_field` / `avg_field` | 协议中的价格字段 / 均价字段 |
| `price_raw` / `avg_raw` | 还原后的原始价格口径 |
| `price_delta_raw` / `aux_delta_raw` | 协议价格差分 / 辅助差分原始值；当日接口可能为 `None` |
| `record_hex` | 单条原始十六进制 |

## 时间和价格口径

| 项目 | 说明 |
| --- | --- |
| 分钟序号 | `index=0` 对应开盘后第一个分时点 |
| 时间标签 | SDK 根据 A 股交易分钟序列生成 `time_label` |
| 日期 | 当前接口不返回日期；要查指定日期用 `client.minutes.history(code, trading_date)` 或 `client.minutes.recent(code, trading_date)` |
| 价格 | SDK 已把协议差分还原成 `price` |
| 均价 | `avg_price` 是服务端返回的均价口径字段 |
