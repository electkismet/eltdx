# 7709-服务器文件下载

## 作用

使用 `0x06b9` 分块读取接口，循环下载服务器上的完整文件。`download_file()` 会根据服务端实际返回长度推进偏移，直到收到空块或短块。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.resources.download_file(path, chunk_size=30000, max_bytes=None)` |
| 底层接口 | [`0x06b9`](../COMMANDS_7709.md#cmd-0x06b9) |
| 返回模型 | `bytes` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    payload = client.resources.download_file("zhb.zip")

print(len(payload))
```

`chunk_size` 控制每次读取的块大小，`max_bytes` 可限制总下载量。文件长度恰好是块大小整数倍时，下载器会再请求一次并在收到空块后结束。

如果只需要读取一个文件块，请使用 [服务器文件分块读取](7709-服务器文件读取.md)。如果要解析 `zhb.zip` 中的统计文件，请使用 [服务器统计文件解析](7709-服务器统计文件解析.md)。
