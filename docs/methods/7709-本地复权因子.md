# 7709-本地复权因子

## 作用

用不复权日 K 和除权除息记录计算本地前复权 / 后复权因子。普通取复权 K 线时，优先直接使用 `0x052d` 的服务端复权参数。

| 项目 | 内容 |
| --- | --- |
| 复权因子 | `client.helpers.factors(code, anchor_date=None)` |
| 本地复权 K 线 | `client.helpers.local_adjusted_kline(code, anchor_date=None, ...)` |
| 数据来源 | [`0x052d`](../COMMANDS_7709.md#cmd-0x052d) + [`0x000f`](../COMMANDS_7709.md#cmd-0x000f) |
| 返回模型 | `FactorResponse` / `KlineSeries` |

这是 SDK 本地工具方法。新版服务端 K 线接口已经支持 `adjust="qfq"`、`adjust="hfq"`、`adjust="fixed_qfq"`、`adjust="fixed_hfq"`，所以只有需要本地复核或自定义处理时才需要这个工具。

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    factors = client.helpers.factors("sz000001")
    anchored = client.helpers.factors("sz000001", anchor_date="2024-05-31")
    local_qfq = client.helpers.local_adjusted_kline("sz000001", period="day", adjust="qfq")
    anchored_qfq = client.helpers.local_adjusted_kline(
        "sz000001",
        period="day",
        adjust="qfq",
        anchor_date="2024-05-31",
    )
```

服务端复权 K 线：

```python
qfq = client.bars.get("sz000001", period="day", adjust="qfq")
hfq = client.bars.get("sz000001", period="day", adjust="hfq")
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `period` | 本地调整 K 线只支持日 K，可传 `day`、`1d`、`d` 或 `daily` |
| `adjust` | `qfq` 或 `hfq` |
| `anchor_date` | 可选的前复权基准日期；取该日期或此前最近交易日，并把其 `qfq_factor` 归一为 `1` |
| `refresh` | 是否跳过股本变迁缓存 |

`anchor_date` 只用于前复权。后复权传入该参数会抛出 `ValueError`。

## 解析字段

| `FactorResponse` 字段 | 含义 |
| --- | --- |
| `count` | 因子数量 |
| `items` | 因子记录 |
| `anchor_date` | 前复权锚点日期；未指定时为 `None` |

| `FactorRecord` 字段 | 含义 |
| --- | --- |
| `time` | K 线时间 |
| `last_close_price` / `last_close_price_milli` | 原上一收盘价 |
| `pre_last_close_price` / `pre_last_close_price_milli` | 除权除息调整后的上一收盘价 |
| `qfq_factor` | 前复权因子 |
| `hfq_factor` | 后复权因子 |

## 计算口径

| 项目 | 说明 |
| --- | --- |
| 基础 K 线 | `client.bars.all(code, period="day", adjust="none")` |
| 除权除息 | `client.helpers.xdxr(code)` |
| 除权后昨收 | 根据分红、配股价、送转股、配股计算 |
| 后复权因子 | 从前往后累计 |
| 前复权因子 | 从后往前累计 |
| 锚点归一 | 每个前复权因子除以锚点日期的前复权因子，使锚点因子等于 `1` |

## 返回示例

不传锚点时，前复权默认以最新交易日为基准：

```python
factors = client.helpers.factors("sz000001")
print(factors.anchor_date)             # None
print(factors.items[0].qfq_factor)     # 0.825
print(factors.items[-1].qfq_factor)    # 1.0
```

指定历史锚点后，全部前复权因子按同一个比例重新缩放：

```python
factors = client.helpers.factors("sz000001", anchor_date="2024-05-31")
print(factors.anchor_date)             # 2024-05-31
print(factors.items[0].qfq_factor)     # 1.0
print(factors.items[-1].qfq_factor)    # 1.212121...
```

锚点只改变因子和复权价格的绝对尺度，不改变各交易日之间的涨跌关系。

本地调整 K 线：

```python
local_qfq = client.helpers.local_adjusted_kline("sz000001", period="day", adjust="qfq")
local_hfq = client.helpers.local_adjusted_kline("sz000001", period="day", adjust="hfq")
```

周线、月线等周期不能用一条日因子直接调整整根 K 线，本地方法会明确拒绝。需要其他周期时使用服务端复权：

```python
weekly_qfq = client.bars.get("sz000001", period="week", adjust="qfq")
```
