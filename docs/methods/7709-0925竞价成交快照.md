# 7709-0925正式撮合

## 作用

从成交明细中扫描 09:25 的正式开盘撮合，返回价格、成交量、成交额和方向状态。目标日期等于主站当前交易日时使用 `0x0fc5`，其他日期使用 `0x0fc6`；`status=8` 的竞价过程快照不会被当作正式成交。

| 项目 | 内容 |
| --- | --- |
| 调用方法 | `client.helpers.auction_0925(code, date)` |
| 数据来源 | 主站当前交易日用 [`0x0fc5`](../COMMANDS_7709.md#cmd-0x0fc5)，其他日期用 [`0x0fc6`](../COMMANDS_7709.md#cmd-0x0fc6) |
| 返回模型 | `Auction0925Result` |

这是 SDK 本地工具方法。它会先读取主站当前交易日：目标日期等于该交易日时使用当日成交明细 `0x0fc5`，其他日期使用历史成交明细 `0x0fc6`；分页扫描并只选择 `time_minutes == 09:25` 且 `event_kind == "opening_match"` 的记录。

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    result = client.helpers.auction_0925("sz000001", "2026-05-20")
    if result.has_auction_0925:
        print(result.price, result.volume, result.amount)
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `date` | 交易日 |
| `page_size` | 扫描成交明细时每页条数 |
| `max_pages` | 最多扫描页数 |

## 解析字段

| `Auction0925Result` 字段 | 含义 |
| --- | --- |
| `code` | 完整代码 |
| `trading_date` | 交易日 |
| `has_auction_0925` | 是否找到 09:25 正式撮合 |
| `price` / `price_milli` | 竞价成交价 |
| `volume` | 成交量，单位手 |
| `amount` | 成交额 |
| `status` / `side` | 原始状态 / 方向 |
| `pages_used` | 扫描了几页成交明细 |
| `source_mode` | 数据来源说明 |

## 使用建议

如果要看竞价阶段过程，用 [7709-集合竞价明细.md](7709-集合竞价明细.md) 或成交明细中的 `auction_snapshots`。如果只要某天 09:25 最终撮合，这个方法更直接。
