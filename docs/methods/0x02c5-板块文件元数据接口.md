# 7709-板块文件元数据

## 作用

在下载板块文件（如 `block_zs.dat`、`block_gn.dat`、`block_fg.dat`）之前，先向主站查询该文件在服务器上的**字节大小与 MD5 摘要**，用于判断本地缓存是否需要更新，或用于校验下载内容的完整性。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.resources.block_meta(filename)` |
| 底层接口 | [`0x02c5`](../COMMANDS_7709.md#cmd-0x02c5) |
| 返回 | `BlockMeta`（`size`、`md5`） |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    meta = client.resources.block_meta("block_gn.dat")
    print(meta.size, meta.md5)
```

拿到元数据后，用 `client.resources.download_file("block_gn.dat")` 下载文件内容，两者比较 MD5 即可判断本地文件是否为最新。

## 怎么选

| 想要的数据 | 调用 | 数据来源 |
| --- | --- | --- |
| 板块文件的服务器大小与 MD5 | `client.resources.block_meta(filename)` | `0x02c5` 直接返回 |
| 板块文件的完整内容 | `client.resources.download_file(filename)` | `0x06b9` 分片下载 |
| 板块的行情/成分股 | `client.helpers.board_quotes()` / `board_member_quotes()` | 板载定义文件 + 快照 |

## 参数

| 参数 | 含义 |
| --- | --- |
| `filename` | 板块文件名，如 `block_zs.dat`、`block_gn.dat`、`block_fg.dat`；最多 40 字节 |

## 返回

| 返回值 | 含义 |
| --- | --- |
| `BlockMeta.size` | 服务器端文件字节数 |
| `BlockMeta.md5` | 服务器端文件的 MD5 摘要字符串（ASCII，去尾零） |

## 使用说明

| 项目 | 说明 |
| --- | --- |
| 底层请求 | `0x02c5` 只传板块文件名（40 字节定长 ASCII） |
| 与内容下载的关系 | `0x02c5` 只取元数据；文件内容由 `0x06b9` 读取接口下载，本命令不返回内容 |
| 校验建议 | 下载后对内容计算 MD5，与 `BlockMeta.md5` 比对 |
| 缓存 | 不缓存；每次调用都会请求主站 |
