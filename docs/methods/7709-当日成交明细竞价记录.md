# 7709-当日成交明细竞价记录

## 作用

从当日成交明细 `0x0fc5` 中筛选集合竞价记录，只保留 `status=8` 的竞价事件。它是成交明细里的分钟记录，不是 `0x056a` 返回的秒级竞价过程快照，也不代表实际成交。

| 项目 | 内容 |
| --- | --- |
| 主要调用 | `client.trades.auction_today(code, ...)` |
| 底层接口 | [`0x0fc5`](../COMMANDS_7709.md#cmd-0x0fc5) |
| 返回模型 | `tuple[TradeTick, ...]` |
| 时间字段 | 只有分钟级时间，没有秒字段 |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    records = client.trades.auction_today("sz000001")

for record in records:
    print(record.time_label, record.price, record.auction_matched_volume)
```

## 解析规则

只返回 `status_raw == 8` 的记录。`volume` 是虚拟匹配量，`order_count` 是带符号未匹配量，`trade_amount_yuan` 只是按价格和数量估算的金额，不代表已经成交。

常用字段包括 `time_label`、`price`、`volume`、`order_count`、`auction_matched_volume`、`auction_unmatched_signed_volume`、`auction_unmatched_volume`、`event_kind` 和 `record_hex`。

如果需要几秒一条、带秒字段的竞价过程，请使用 [`client.auctions.series(code)`](7709-集合竞价明细.md)。如果需要 09:25 正式撮合，请使用 [当日 09:25 正式撮合](7709-当日0925正式撮合.md)。
