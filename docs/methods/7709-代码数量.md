# 7709-市场代码数量

## 作用

查询沪、深、北某个市场的完整代码表条数。这个数字不限 A 股，还包括 B 股、ETF、指数、债券及主站代码表中的其他证券代码。

| 项目 | 内容 |
| --- | --- |
| 市场全部代码数 | `client.codes.count(market)` |
| 仅 A 股数量 | `client.codes.a_share_count(market)` |
| 底层接口 | 全部代码数直接使用 [`0x044e`](../COMMANDS_7709.md#cmd-0x044e)；A 股数量基于 `0x044d` 代码表本地筛选 |
| 返回 | `int` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    sh_total = client.codes.count("sh")
    sz_total = client.codes.count("sz")
    bj_total = client.codes.count("bj")

    sh_a_share = client.codes.a_share_count("sh")
    sz_a_share = client.codes.a_share_count("sz")
    bj_a_share = client.codes.a_share_count("bj")
```

如果要具体代码，不需要先查数量，直接调用 `client.codes.all(market)`；它会自动翻页直到取完。

## 怎么选

| 想要的数据 | 调用 | 数据来源 |
| --- | --- | --- |
| 某市场完整代码表条数 | `client.codes.count("sh")` | `0x044e` 直接返回 |
| 某市场 A 股数量 | `client.codes.a_share_count("sh")` | 拉取 `0x044d` 代码表后按 `a_share` 本地统计 |
| 某市场具体代码和名称 | `client.codes.all("sh")` | 自动分页拉取 `0x044d` 代码表 |

## 参数

| 参数 | 含义 |
| --- | --- |
| `market` | 市场，支持 `sz`、`sh`、`bj`，也支持 `0`、`1`、`2` |

## 返回

| 返回值 | 含义 |
| --- | --- |
| `int` | 所选口径的数量；`count()` 是市场完整代码表条数，`a_share_count()` 仅为 A 股数量 |

## 使用说明

| 项目 | 说明 |
| --- | --- |
| 底层请求 | `0x044e` 只传市场和客户端日期 |
| `count()` 返回内容 | 只返回市场完整代码表条数，不返回具体代码，也不区分证券品种 |
| `a_share_count()` 实现 | 自动拉取该市场完整代码表，再按本地派生的 `a_share` 分类计数 |
| 具体代码 | 直接使用 [7709-代码表.md](7709-代码表.md) 的 `client.codes.all(market)` |
| 缓存 | 不缓存；每次调用都会请求主站 |
