# v3.0.2

`v3.0.2` 明确区分成交明细里的原始混合记录、真实成交和集合竞价快照，并为 7709 与 Helpers 文档补齐真实返回样本。

## 主要变化

- `TradePage.actual_trades` 保留所有真实成交，只排除 `status=8` 集合竞价快照；原始 `ticks` 继续完整保留服务器记录。
- `TradeTick.is_actual_trade` 可直接判断记录是否为真实成交。
- `TradePage.after_hours_trades` 和 `TradeTick.is_after_hours_fixed_price` 可识别 15:05-15:30、`status=5` 的盘后固定价格成交。
- 修复显式 `connect()` 握手期间并发 `close()` 时仍切换备用服务器的问题，关闭中断现在会立即停止连接流程，避免无谓的 `CloseTimeout`。
- 21 个 7709 原生接口和 16 个 Helpers 页面新增真实 JSON 样本，默认折叠、支持复制和长内容滚动；21 个 F10 原生 Entry 页面不新增样本。

## 数据口径

`status=8` 记录仍保存在 `ticks`，但不会进入 `actual_trades`。成交明细不再把它的 `volume` 和 `order_count` 推断为虚拟匹配量或未匹配量；完整秒级竞价价格、虚拟匹配量和未匹配量继续以 `client.auctions.series()` 的 `0x056a` 数据为准。

09:25 正式开盘撮合、15:00 正式收盘撮合、普通盘中成交以及 15:05-15:30 的 `status=5` 盘后固定价格成交都属于真实成交，不会被过滤。

## 安装和平台

```bash
python -m pip install --upgrade "eltdx==3.0.2"
```

发布产物仍为 Windows x64、manylinux x64/ARM64、macOS x64/ARM64 五个独立 ABI3 wheel 和一个 sdist，支持普通 GIL CPython 3.10-3.14。

## 升级注意

原有 `client.trades.today()`、`all_today()`、`history()` 和 `all_history()` 调用方式不变。需要服务器原始混合记录时继续使用 `page.ticks`；只分析真实成交时改用 `page.actual_trades`；只分析盘后固定价格成交时使用 `page.after_hours_trades`。

本次没有删除公开接口，也没有改变 `ticks` 的原始记录保留规则。新增属性是只读派生视图，不会额外请求服务器。

## 验证和发布状态

发布流水线为同一提交构建五个 ABI3 wheel 和一个 sdist，在各目标平台安装验证后，将同一批产物上传 PyPI 并附加到 GitHub Release。
