# v3.1.5

`v3.1.5` 统一涨停列表板位字段，清理冗余公开字段，并补全实时涨停梯队与 F10 涨跌停列表文档。

## 主要变化

- `LimitBoardLadderRow` 删除冗余的 `ladder_days` 字段，统一使用 `board_level` 表示该股票实际板位。
- `consecutive_limit_days` 和原生 `lbts` 仍可用于读取同一板位值，不再额外暴露第二个同义字段。
- 实时涨停梯队文档补充 7709 行情、`0x06b9` 统计资源、盘口封单、过滤和排序流程。
- F10 涨跌停列表文档补充 `ztlb`、`lbts`、`zglb`、`fde`、`status`、`reason` 和市场概况字段口径。

## 修复内容

- 避免 `board_level` 与 `ladder_days` 同时表达同一含义，减少调用方字段选择和序列化歧义。
- 明确 `fde` 按 `ztlb` 解释为涨停封单或跌停封单，炸板行通常为零。
- 更正文档入口名称和链接，F10 页面统一使用“涨跌停列表”。

## 测试

- F10、MCP、页面契约测试通过。
- `ruff check src tests` 通过。
- `mkdocs build --strict` 通过。

## 升级注意

新代码请使用 `row.board_level`。如果代码依赖 `row.ladder_days`，需要改为 `row.board_level`；`row.consecutive_limit_days` 和 `row.lbts` 仍可读取该值。

```bash
python -m pip install --upgrade "eltdx==3.1.5"
```
