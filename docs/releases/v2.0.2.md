# v2.0.2

`v2.0.2` 是相对 `v2.0.1` 的文档与接口目录整理版本，不改变现有 Python API 名称和协议解析行为。

## 更新说明

- 拆分当日、历史成交明细与对应的竞价记录、09:25 正式撮合文档，每个公开入口都有独立说明和示例。
- 拆分服务器文件分块读取、完整下载、统计文件解析文档，分别说明 `client.resources.read()`、`download_file()` 和 `read_stats()`。
- 更新 README、方法索引、7709 命令对照和 GitHub Pages 接口目录，目录标题不再把“分钟级/秒级”写进名称，时间粒度改在正文中说明。
- Pages 接口目录从 59 个公开入口扩展为 60 个独立详情页，消除多个入口共用一个主文档的问题。

## 验证

- `pytest -q tests/test_pages.py`：23 项通过。
- `mkdocs build --strict`：通过。

pip install -U "eltdx==2.0.2"
