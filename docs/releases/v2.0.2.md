# v2.0.2

`v2.0.2` 是相对 `v2.0.1` 的文档整理版本，不改变现有 Python API 名称、返回模型或协议解析行为。

## 更新说明

- 成交明细相关页面重新整理：当日成交明细、历史成交明细、成交明细中的竞价记录，以及当日和历史 09:25 正式撮合，分别提供独立说明和示例。
- 服务器资源相关页面重新整理：`client.resources.read()`、`client.resources.download_file()` 和 `client.resources.read_stats()` 分别说明各自的用途、返回值和示例。
- GitHub Pages 的接口目录和方法索引同步更新，用户可以直接从目录进入对应接口的页面；时间粒度等区别放在正文说明中，不再塞进接口名称。

本版本只调整文档和 Pages 展示，已有代码调用不需要修改。

## 安装

```bash
pip install -U "eltdx==2.0.2"
```
