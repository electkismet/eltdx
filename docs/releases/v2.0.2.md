# v2.0.2

`v2.0.2` 是相对 `v2.0.1` 的集合竞价接口整理版本，明确区分竞价过程、竞价记录和 09:25 正式撮合。

## 更新说明

- 新增 `client.trades.auction_today(code)`，从 `0x0fc5` 当日成交明细中筛选集合竞价记录。
- 新增 `client.trades.auction_history(code, date)`，从 `0x0fc6` 历史成交明细中筛选指定日期的集合竞价记录。
- 新增 `client.trades.opening_match_today(code)`，从 `0x0fc5` 当日成交明细中提取 09:25 正式撮合。
- 新增 `client.trades.opening_match_history(code, date)`，从 `0x0fc6` 历史成交明细中提取指定日期的 09:25 正式撮合。
- `client.auctions.series(code)` 保持不变，继续返回 `0x056a` 的集合竞价过程快照；该接口不用于获取 09:25 正式成交。
- 删除原先合并当日/历史查询的 `client.trades.auction_snapshots()` 和 `client.helpers.auction_0925()` 入口，改用以上明确的当日、历史接口。
- 当日成交明细、历史成交明细、竞价记录和正式撮合分别补充独立的调用说明与示例。

普通成交明细接口 `client.trades.today()`、`all_today()`、`history()` 和 `all_history()` 的调用方式不变。

## 安装

pip install -U "eltdx==2.0.2"
