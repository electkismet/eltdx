# v3.2.1

## 主要变化

- 新增 `client.helpers.board_quotes()`，读取 `0x06b9` 板块资料并通过 `0x054c` 批量取得板块行情。
- 新增 `client.helpers.board_member_quotes(board_code)`，按板块代码读取成分股，使用 `0x044d` 当前证券名单过滤无效记录，再通过 `0x054c` 按每批最多 80 只取得行情。
- 板块资料按服务端日期每日缓存；当天已准备过时直接复用，传入 `refresh=True` 可强制更新。
- 保留原始成员、有效成员和排除成员信息；接口不自行排序，排序由调用方或服务端分类行情接口决定。
- 明确 `client.quotes.list_by_category()` 是 `0x054b` 原始分页接口，`client.helpers.realtime_rank()` 是基于它的榜单封装。

## 修复内容

- 修正文档接口目录中分类行情与实时榜单看起来重复的问题，标注两者的底层与封装关系。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.2.1"
```
