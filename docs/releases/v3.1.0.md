# v3.1.0

`v3.1.0` 新增 7709 `0x0ffc` 日资金流向接口，并将它同步到 Python API、MCP 和文档目录。

## 主要变化

- 新增 `client.money_flow.daily(code, *, include_raw=False, batch_size=75)`。
- 支持传入单只或多只股票代码；多代码调用返回 `MoneyFlowBatch`，默认批次为 75，可调整。
- 返回主力净额、主买净额及两种口径各自的超大单、大单、中单、小单净额。
- 保留主站返回的 `buckets`、21 个 `raw` 字段和 `record_hex`，便于继续核对原始数据。
- 接口目录和独立详情页补充输入、输出字段和真实返回示例。

## 修复内容

- 修正资金流向详情页和接口目录对主力、主买四档字段的展示，避免将两种统计口径混淆。
- 保留 `0x0ffc` 原始分档和辅助字段，确保 MCP 与 Python API 返回口径一致。

## MCP

- 新增 `eltdx_money_flow` 工具，对应 `client.money_flow.daily()`。
- 支持单只或多只代码、`include_raw`、`batch_size`、`timeout` 和 `host` 参数。
- MCP 服务版本与 Python 包同步为 `3.1.0`。

## 安装和平台

本版本支持 CPython 3.10-3.14，使用 `cp310-abi3` 产物：Windows x64、Linux x64、Linux ARM64、macOS x64 和 macOS ARM64 五个独立 ABI3 wheel，另有一个源码包。

## 安装

```bash
python -m pip install --upgrade "eltdx==3.1.0"
```

## 升级注意

现有 API 保持兼容；需要读取日资金流向时使用 `client.money_flow.daily()`，需要 MCP 时重新安装 `eltdx[mcp]` 并重启 MCP 客户端以发现新工具。
