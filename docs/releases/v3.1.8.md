# v3.1.8

`v3.1.8` 增加批量成交字段接口，并补齐分时接口和 MCP 工具的多股票调用能力。

## 主要变化

- 新增 `TradeBatch`，支持按列读取、按索引筛选，以及按需转换为 `TradeTick` / `TradePage`。
- 新增 `trades.today_batch()`、`trades.all_today_batch()`，并保留原有成交接口兼容性。
- 新增历史成交批量入口 `trades.history_batch()` / `all_history_batch()`；四个批量入口均支持单个代码或代码列表。
- 分时接口 `minutes.today()` / `history()` / `recent()` 新增代码列表和 `batch_size`；这些入口在 `v3.1.7` 仍只接受单个代码。
- MCP 的 `eltdx_minute`、`eltdx_trades` 新增代码列表和 `batch_size`；Python 成交接口的代码列表能力在 `v3.1.7` 已存在。
- `TradeBatch` 复用现有 Rust native DTO；本版本没有修改 Rust 协议或 ABI。
- 同步更新 API、MCP、字段、方法和包内文档镜像。

## 修复内容

- 修复 MCP 工具签名契约与批量参数不同步的问题。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.1.8"
```
