# v3.0.1

`v3.0.1` 修正集合竞价历史数据来源，并统一当日与历史竞价过程的公开入口和文档口径。

## 主要变化

- `client.auctions.series(code, date=None)` 继续使用 `0x056a`：不传日期查询当日，传入日期查询指定历史交易日的完整集合竞价过程快照。
- `client.helpers.auction_data(code, date=None)` 聚合竞价过程、09:25 正式撮合和前收盘参考价，并计算开盘价、开盘量、开盘额和开盘涨幅。
- 历史聚合使用 `0x056a(date=YYYYMMDD)` 查询竞价过程，使用 `0x0fc6` 查询 09:25 正式撮合和前收盘价格基数。
- 删除容易把成交明细误认为完整竞价过程的 `client.trades.auction_today()`、`auction_history()` 以及对应 MCP 工具；成交明细和 09:25 正式撮合入口保持可用。
- 文档和接口目录统一使用“集合竞价过程快照”“集合竞价数据”和“前收盘参考价”等准确名称。

## 数据口径

`series.points` 保存主站返回的全部过程时间点，每条记录包含时分秒、竞价价格、虚拟匹配量和未匹配量。`snapshot_0925` 是独立的 09:25 正式成交，不能与过程中的虚拟匹配量混用。

`pre_close_price` 是计算当日涨跌幅的前收盘参考价。普通交易日它等于上一交易日收盘价；除权除息日它是调整后的除权参考价，可能不等于上一根不复权日 K 的收盘价。

## 安装和平台

```bash
python -m pip install --upgrade "eltdx==3.0.1"
```

发布产物仍为 Windows x64、manylinux x64/ARM64、macOS x64/ARM64 五个独立 ABI3 wheel 和一个 sdist，支持普通 GIL CPython 3.10-3.14。

## 升级注意

需要完整竞价过程时统一使用 `client.auctions.series()`；需要竞价过程、正式开盘结果和前收盘参考价的组合结果时使用 `client.helpers.auction_data()`。

`client.trades.today()`、`all_today()`、`history()`、`all_history()` 仍用于成交明细；`opening_match_today()` 和 `opening_match_history()` 仍用于只取 09:25 正式撮合。

## 验证和发布状态

发布流水线为同一提交构建五个 ABI3 wheel 和一个 sdist，在各目标平台安装验证后，将同一批产物上传 PyPI 并附加到 GitHub Release。
