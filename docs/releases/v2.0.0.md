# v2.0.0

`v2.0.0` 清理了 `TdxClient` 上长期保留的旧版扁平兼容入口，统一使用按功能组织的模块化 API。

## 主要变化

- 删除 `client.get_quote()`、`client.get_kline()`、`client.get_minute()`、`client.get_trades()` 等旧 `get_*` 入口。
- 7709 原生能力统一放在 `client.codes`、`client.quotes`、`client.bars`、`client.minutes`、`client.trades`、`client.auctions`、`client.corporate` 和 `client.resources`。
- 7615 原生 Entry 能力继续通过 `client.f10` 提供。
- 本地组合、筛选和计算能力统一放在 `client.helpers`。
- 保留原生 `client.quotes.legacy()` (`0x053e`) 和 `client.resources.read()` (`0x06b9`)。

这是不兼容更新。安装升级本身不受影响，但调用旧方法的代码需要迁移。完整对照见 [迁移到 eltdx 2.0](../MIGRATION_FROM_OLD.md)。

## 安装

```bash
pip install -U "eltdx==2.0.0"
```

MCP 用户：

```bash
pip install -U "eltdx[mcp]==2.0.0"
```
