# v3.0.9

`v3.0.9` 为成交明细接口增加代码列表批量查询能力。

## 主要变化

- `client.trades.today()`、`history()`、`all_today()`、`all_history()` 支持传入代码列表。
- `opening_match_today()` 和 `opening_match_history()` 同样支持代码列表。
- 列表调用返回以规范化完整代码为键的结果字典，单个代码调用的返回类型保持不变。
- 默认并发数自动跟随连接池 Slot 数；列表没有总数量上限，超过并发数的代码排队等待并复用 Slot。

## 底层行为

- `0x0fc5` 和 `0x0fc6` 二进制协议仍是一只股票一条请求，批量能力由 Python 客户端并发调度实现。
- 每只股票内部的成交分页仍按顺序执行，多只股票之间可以并发。
- 自动分页、空页终止和 `max_pages` 保护规则保持不变。

## 修复内容

- 修复成交相关入口只能接收单个股票代码的问题，并补充列表输入、代码规范化、并发和排队回归测试。

## 安装和平台

本版本支持 CPython 3.10-3.14，使用 `cp310-abi3` 产物：Windows x64、Linux x64、Linux ARM64、macOS x64 和 macOS ARM64 五个独立 ABI3 wheel，另有一个源码包。

## 安装

```bash
python -m pip install --upgrade "eltdx==3.0.9"
```

## 升级注意

单个代码的现有调用无需修改；需要批量查询时，直接把 `code` 参数替换为代码列表即可。
