# v3.0.3

`v3.0.3` 补齐 A 股常用业务封装，并把 AxData 对照后确认缺失的短线字段加入当前 Helpers 返回模型。

## 主要变化

- 新增 `client.helpers.latest_stock_list()`、`latest_st()`、`latest_suspended()`。
- 新增 `client.helpers.daily_share_capital()`、`daily_price_limits()` 和 `realtime_rank()`。
- 新增 `client.helpers.limit_ladder()`、`theme_strength_rank()`，用于连板天梯和题材强度聚合。
- 新增 `client.helpers.buy_sell_strength()`、`volume_comparison()` 命名入口。
- `ShortlineIndicator` 增加开盘价、昨收、开盘涨幅、开盘量、开盘量比、普通流通股本、普通流通市值、封单等字段。
- `open_volume_ratio` 使用最近 5 个完整交易日的日 K 成交量，数据不足时返回 `None`。
- 保留原有 7709 原生接口和现有 Python API；新增能力全部位于 `codes`、`minutes` 和 `helpers` 业务层。

## 数据口径

- 最新股票和 ST 列表来自 `0x044d` 代码表。
- 停牌扫描使用保留的 `0x053e` 原生批量行情交易状态位 `0x20`。
- 每日涨跌停价是按实时昨收、市场板块、ST/新股规则计算的标准化结果，不新增协议号。
- `opening_rush` 仅使用 `0x054b` 分类行情明确提供的字段，不猜测快照尾部字节。

## 安装和平台

本版本继续支持 CPython 3.10-3.14，并发布五个独立 ABI3 wheel：Windows x64、Linux x64、Linux ARM64、macOS x64 和 macOS ARM64；同时发布一个源码包。

```bash
python -m pip install --upgrade "eltdx==3.0.3"
```

## 升级注意

原有 `client.codes`、`client.quotes`、`client.minutes`、`client.trades`、`client.auctions`、`client.corporate`、`client.f10` 和 `client.helpers` 入口继续保留。

新增封装会按需组合现有原生接口；列表和榜单的结果时间取决于所连接行情服务器的数据时间。`open_volume_ratio` 在历史日 K 不足 5 个完整交易日时返回 `None`，不使用不完整样本推算。

## 验证和发布状态

Python 回归、Rust workspace 测试、公开 API 契约和发布元数据在发布前统一验证。GitHub Actions 使用同一批产物完成安装检查，并将验证通过的五个 wheel 和一个源码包直接发布到 PyPI 与 GitHub Release，不重复构建。
