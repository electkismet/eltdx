# v3.4.0-beta.1

eltdx 的双端公开测试版。Python 和 Rust 包从同一份源码构建，共用 Rust 核心。Python 用户继续使用原来的导入、参数和返回模型；Rust 用户直接用 Cargo，不需要安装 Python。

## 安装

Python 的包仓库按 PEP 440 将 `3.4.0-beta.1` 写成 `3.4.0b1`：

```sh
python -m pip install --pre "eltdx==3.4.0b1"
```

Rust 需要 Rust 1.89 或更新版本。在 `Cargo.toml` 中写入：

```toml
[dependencies]
eltdx = "=3.4.0-beta.1"
```

保持稳定版的 Python 用户可以继续使用 `3.3.5`。预发布版本需要主动选择。

## 试用范围

- Rust 默认提供同步 HQ 行情 API，可按需启用 `offline`、`f10`、`ex`、`mac` 和 `serde`。参见 [Rust 使用指南](../rust-sdk/user-guide.md)。
- Python 在原有接口下复用 Rust 实现。欢迎反馈与 `3.3.5` 相比出现的行为差异，尤其是查询结果、自定义 transport 和关闭后重新连接。
- MAC-EX 在 Rust 中仍需要显式提供已核实的登录判定规则；实验接口及主站可达性不作稳定承诺。

项目继续采用原有的学习与非商业数据研究许可。请到 [GitHub Issues](https://github.com/electkismet/eltdx/issues/new) 反馈，并附上包版本、操作系统、最小复现和错误信息。
