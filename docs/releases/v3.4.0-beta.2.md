# v3.4.0-beta.2

本轮双端测试版新增三个原生 Rust 入口：`eltdx` 命令行、`eltdx-http` HTTP/WebSocket 网关和 `eltdx-mcp` stdio 服务。三个入口直接使用 Rust SDK，运行时无需 Python。

## 安装与构建

- Python 包版本为 `3.4.0b2`：`python -m pip install --pre "eltdx==3.4.0b2"`。
- Rust SDK 的 Cargo 依赖为 `eltdx = "=3.4.0-beta.2"`，最低 Rust 1.89。
- 原生工具从本标签的仓库源码构建：在仓库根目录运行 `cargo build --locked --release -p eltdx-tools --bins`，产物位于 `target/release/`。详见[构建和启动说明](https://github.com/electkismet/eltdx/tree/v3.4.0-beta.2#从源码构建-rust-工具)。

## 变更与限制

- 网关支持 WebSocket 实时订阅、原始推送轮询，以及关联订阅后对多证券推送的解析。Python 回调不能通过 JSON 传入，网关客户端可使用 WebSocket 订阅。
- 四个 F10 集合查询支持缓存与显式刷新；扩展行情 CLI 支持域名参数。
- Rust 网关的部分原始响应字段与 Python 网关不同。MAC-EX、联网场外基金和 MCP 宏观工具需要通过 `ELTDX_MAC_EX_LOGIN_RULES` 提供经验证的登录规则。
- 新增入口仅做了有针对性的构建和本机检查，未做正式行情源的全量对照验收。
