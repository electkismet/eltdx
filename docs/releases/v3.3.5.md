# v3.3.5

发布日期：2026-11-06。

本版本修复 EX 扩展行情的连接初始化与 MAC-EX 主机探活，改善部分主站查询市场、报价和 K 线时超时的问题。

## 主要变化

- EX 连接建立后自动完成会话初始化，并完整读取响应后再发送业务请求。
- EX 默认探活使用市场列表查询，帮助选出能够提供数据的主站。
- MAC-EX 的 `ping_all()` 与 `from_best_host()` 使用 MAC-EX 连接模式和登录命令，与正式连接流程保持一致。

## 修复内容

- 补齐 EX 数据查询前所需的 92 字节初始化请求，避免仅建立 TCP 连接后业务请求无响应。
- 完整读取初始化响应的帧头和响应体，避免后续业务响应错位。
- MAC-EX 正式连接和探活均跳过 EX 初始化流程，使用自身的登录流程。
- 增加初始化响应读取、失败清理、模式选择及两个 MAC-EX 探活入口的回归测试，并订正文档说明。

## 兼容性与使用

- 现有 `ExTdxClient` 和 `MacExClient` 高层调用方式保持不变。
- 底层 `ExTdxConnection` 新增 `send_setup` 参数，默认开启 EX 初始化；MAC-EX 模式自动跳过。
- 本次主要影响 EX / MAC-EX 扩展行情；沪深 A 股行情订阅用法保持不变。
- 实际数据覆盖和可用性依主站、品种及查询时段而定。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.3.5"
```
