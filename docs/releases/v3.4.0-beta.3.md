# v3.4.0-beta.3

发布日期：2026-11-27。

- 修复 Python `market_stat()` 和 Rust SDK 全市场统计中涨跌、平盘、总数及涨跌停家数放大十倍的问题。
- 同步更新文档和回归测试。感谢 [jerasky](https://github.com/jerasky) 在 [PR #33](https://github.com/electkismet/eltdx/pull/33) 中贡献修复。
- 如果调用方曾将这些家数除以 10，请移除该补偿。
- Python 安装命令为 `python -m pip install --pre "eltdx==3.4.0b3"`。
- Rust SDK 依赖为 `eltdx = "=3.4.0-beta.3"`，最低 Rust 1.89。
- 原生工具可从本标签源码构建，运行 `cargo build --locked --release -p eltdx-tools --bins`。
