# v3.1.6

`v3.1.6` 修复证券代码表精度未用于行情解析的问题，完善可转债快照和分时支持。

## 主要变化

- `0x044d` 代码表的 `decimal` 字段现在注册为客户端行情精度元数据。
- 快照、旧版行情、分类行情、刷新行情和推送行情按证券自身精度解析。
- 当日、历史和近期分时按代码表精度计算价格、毫厘价格和均价。
- 客户端按市场懒加载并缓存代码表，后续请求复用精度信息。
- 修复 `include_raw` 开关：`False` 时清空 `raw_payload` / `record_hex`，`True` 时保留原始响应内容。

## 修复内容

- 修复沪深可转债快照、分时价格放大 100 倍的问题。
- 移除按 `11xxxx/12xxxx` 前缀判断精度的临时规则。
- K 线 `0x052d` 解析保持不变。

## 测试

- Rust 协议测试：69 项通过。
- Python 公共 API、DTO 合约测试通过。
- 全接口真实主站测试通过。
- 实测 `sh118076`、`sz127089` 的快照、分时和 K 线价格正常。

## 升级注意

客户端会在首次请求某市场行情时加载该市场代码表，之后在客户端生命周期内复用缓存。

```bash
python -m pip install --upgrade "eltdx==3.1.6"
```
