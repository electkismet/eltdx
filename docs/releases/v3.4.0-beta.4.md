# v3.4.0-beta.4

发布日期为 2026-11-28。

## 主要变化

- 修复近期分时数据日期偏差和定宽名称字段乱码。

## 修复内容

- 修复近期分时日期选择器，避免指定日期时收到其他交易日的分时数据。代码仍保留旧 Rust 常量供已有调用方使用，并标记为弃用。 [PR #34](https://github.com/electkismet/eltdx/pull/34)
- 修复公司资料目录的栏目名、文件名和证券简称末尾偶尔出现乱码的问题。 [PR #35](https://github.com/electkismet/eltdx/pull/35)
- 更新近期分时的 Python 和 Rust 文档，替换了日期标错的样本。感谢 jerasky 提交两项修复。

## 升级

```bash
python -m pip install --upgrade --pre "eltdx==3.4.0b4"
```

Rust 1.89 或更新版本可在应用的 `Cargo.toml` 中锁定测试版。

```toml
[dependencies]
eltdx = "=3.4.0-beta.4"
```

从本版本源码构建 CLI、网关和 MCP 服务时，运行 `cargo build --locked --release -p eltdx-tools --bins`。
