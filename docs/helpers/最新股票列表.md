# 最新股票列表

获取当前代码表中的沪深北 A 股证券列表。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.latest_stock_list(market=None)` |
| 返回 | `list[SecurityCode]` |
| 数据来源 | `0x044d` 代码表 |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    rows = client.helpers.latest_stock_list()
    print(rows[0].full_code, rows[0].name)
```

`market` 可选 `sh`、`sz` 或 `bj`；不传时返回全部沪深北 A 股。返回的是当前代码表快照，不包含历史上市或退市记录。
