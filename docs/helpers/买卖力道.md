# 买卖力道

获取单只证券按分钟整理的买卖力道副图序列。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.buy_sell_strength(code, include_raw=False)` |
| 返回 | `MinuteAuxSeries` |
| 数据来源 | `0x051b` 分时副图 |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    series = client.helpers.buy_sell_strength("sz000001")
    for point in series.points[:5]:
        print(point.time_label, point.buy_commission, point.sell_commission)
```

返回序列按分钟排列，适合绘图或盘中比较；它不是逐笔成交明细。

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 证券代码 |
| `include_raw` | 是否保留原始响应，默认 `False` |

## 返回字段

返回 `MinuteAuxSeries`，序列元数据为 `exchange`、`market_id`、`code`、`full_code`、`selector_raw`、`kind`、`points`、`raw_payload` 和 `count`。每个点包含 `index`、`time_label`、`series_a`、`series_b`、`buy_commission`、`sell_commission`、`previous_day_cumulative_volume`、`current_day_cumulative_volume`、`cumulative_volume` 和 `record_hex`；买卖力道通常使用前两个 commission 字段，其他字段可能为 `None`。
