# 集合竞价数据

## 作用

把集合竞价过程、09:25 正式撮合和前收盘参考价放到一个结果里，并计算开盘价、开盘成交量、开盘成交额和开盘涨幅。

| 项目   | 内容                                                                                                                                    |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 调用方法 | `client.helpers.auction_data(code, date=None)`                                                                                             |
| 返回模型 | `AuctionData`                                                                                                                         |
| 当日来源 | [`0x056a` 集合竞价过程快照](../methods/7709-集合竞价明细.md) + `0x0fc5` 09:25 正式撮合 + [`0x054c` 批量快照](../methods/7709-批量快照.md)中的前收盘参考价 |
| 历史来源 | `0x056a` 指定日期集合竞价过程快照 + `0x0fc6` 历史 09:25 正式撮合和前收盘价格基数 |

`pre_close_price` 表示主站用于计算当日涨跌幅的前收盘参考价。普通交易日它等于上一交易日收盘价；除权除息日它是调整后的除权参考价，可能不等于上一根不复权日 K 的收盘价。

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    today = client.helpers.auction_data("sz000001")
    history = client.helpers.auction_data("sz000001", "2026-05-20")

print(today.open_price, today.open_change_pct, today.open_volume, today.open_amount)

if history.series:
    for point in history.series.points[:5]:
        print(point.time_label, point.price, point.matched_volume, point.unmatched_volume)

print(history.snapshot_0925, history.pre_close_price, history.open_change_pct)
```

## 返回示例

下面只展开聚合结果中的主要字段；`series` 和 `snapshot_0925` 内仍保留各自的完整模型字段：

```python
{
    "code": "sz000001",
    "trading_date": "2026-05-20",
    "series": AuctionSeries(
        trading_date=date(2026, 5, 20),
        points=(
            AuctionPoint(time_label="09:24:57", price=10.52, matched_volume=31800, ...),
            ...,
        ),
    ),
    "snapshot_0925": TradeTick(
        time_label="09:25",
        price=10.55,
        volume=32145,
        event_kind="opening_match",
        ...,
    ),
    "pre_close_price": 10.31,
    "open_price": 10.55,
    "open_volume": 32145,
    "open_amount": 33912975.0,
    "open_change_pct": 2.3278,
}
```

## 参数

| 参数                 | 含义                         |
| ------------------ | -------------------------- |
| `code`             | 股票代码                       |
| `date`             | 不传时查询当日；传入日期时查询该历史交易日 |
| `include_series`   | 是否使用 `0x056a` 返回竞价过程，默认 `True`；当日和历史都通过 `series` 返回主站全部时间点 |
| `include_snapshot` | 是否请求 09:25 正式撮合，默认 `True` |
| `include_quote`    | 是否自动补前收盘参考价，默认 `True`；当日取自 `0x054c`，历史取自 `0x0fc6`，历史查询不会使用当前行情 |
| `pre_close_price`  | 可手动指定前收盘参考价并覆盖接口值；通常不需要传 |

## 返回字段

| 字段                | 含义                                           |
| ----------------- | -------------------------------------------- |
| `code`            | 完整代码                                         |
| `trading_date`    | 交易日                                          |
| `series`          | `AuctionSeries | None`，当日或历史 `0x056a` 集合竞价过程快照 |
| `snapshot_0925`   | `TradeTick | None`，09:25 正式撮合记录             |
| `pre_close_price` | 前收盘参考价；普通日为昨收，除权除息日为调整后的除权参考价 |
| `open_price`      | 开盘价，优先来自 09:25 正式撮合                            |
| `open_volume`     | 09:25 成交量，单位手                                |
| `open_amount`     | 09:25 成交额                                    |
| `open_change_pct` | 开盘涨幅，按 `open_price / pre_close_price - 1` 计算 |

## 两类数据怎么用

| 数据 | 看什么 |
| --- | --- |
| `series.points` | 当日或历史竞价过程中的价格、虚拟匹配量和未匹配量变化；时间点按主站原样返回 |
| `snapshot_0925` | 当日或历史 9:25 的正式成交价、成交量和成交额 |

开盘涨幅和开盘金额通常看 `snapshot_0925` 更直接；当日和历史竞价过程都看 `series.points`。

不传日期时，接口使用 `0x056a(date=0) + 0x0fc5 + 0x054c`。传入日期时，使用 `0x056a(date=YYYYMMDD)` 取得完整竞价过程，再用 `0x0fc6` 自动分页取得 09:25 正式撮合和 `price_base_raw_f32` 前收盘参考价。`0x056a` 的过程数据不会按固定时间范围过滤、截断或去重。
