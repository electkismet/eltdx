# 实时榜单

分页读取分类行情并整理成带排名的实时榜单。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.realtime_rank(category="沪深A股", sort_by="涨幅", count=80, ascending=False)` |
| 返回 | `RealtimeRankTable` |
| 数据来源 | `0x054b` 分类行情 + 代码表名称 |

## 返回字段

每行 `RealtimeRankRow` 包含 `rank`、`full_code`、`name`、`last_price`、`pre_close`、`change_pct`、`amount`、`volume_hand`、`opening_rush` 和 `seal_amount`。

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    table = client.helpers.realtime_rank(sort_by="涨幅", count=20)
    for row in table.rows[:5]:
        print(row.rank, row.full_code, row.change_pct)
```

`sort_by` 使用服务器分类行情支持的排序字段；`count=None` 时持续分页直到服务器返回空页。
