# 连板天梯

从短线指标中筛选封板或触板证券，按连板级别和封单金额整理。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.limit_ladder(codes=None, include_touched=False, count=None)` |
| 返回 | `LimitLadderTable` |
| 数据来源 | 短线指标、实时快照和 `0x06b9` 统计资源 |

## 输入参数

| 参数 | 是否必填 | 说明 |
| --- | --- | --- |
| `codes` | 否 | 股票代码或代码列表；不传时扫描全部 A 股 |
| `include_touched` | 否 | 是否包含触板但未封板的股票，默认 `False` |
| `count` | 否 | 最多返回条数；传 `None` 返回全部，必须为正整数 |

## 返回字段

`LimitLadderTable` 包含以下字段：

| 字段 | 含义 |
| --- | --- |
| `trade_date` | 目标交易日 |
| `rows` | `ShortlineIndicator` 行列表；每行包含短线指标的全部字段，并重点使用 `full_code`、`limit_status`、`ladder_level`、`seal_amount`、`last_price`、`change_pct` |
| `count` | 行数 |

`rows` 中每行的完整字段定义见 [短线指标](短线指标.md) 的“指标字段”章节。

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    table = client.helpers.limit_ladder(count=30)
    for row in table.rows:
        print(row.full_code, row.ladder_level, row.seal_amount)
```

默认只返回已封板股票；传 `include_touched=True` 时同时包含触板但未封板股票。大范围扫描建议传入候选代码。
