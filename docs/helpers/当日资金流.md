# 当日个股资金流向

## 作用

按当日 L1 逐笔成交统计一只股票的资金流向分布：把每笔成交按**金额**分为超大单 / 大单 / 中单 / 小单，再按买卖方向分别累加，得到四档流入与四档流出。

| 档位 | 金额区间 |
| --- | --- |
| 超大单 | > 100 万元 |
| 大单 | 20 万 ~ 100 万元 |
| 中单 | 4 万 ~ 20 万元 |
| 小单 | ≤ 4 万元 |

单笔金额 = 成交价 × 成交量 × 100。

## 调用

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.today_fund_flow(code)` |
| 底层接口 | `0x0fc5`（[当日成交明细](7709-当日成交明细.md)），自动分页取全量 |
| 返回 | `FundFlow` |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    flow = client.helpers.today_fund_flow("sz000001")
    print("主力净流入", flow.main_net_inflow)
    print("全单净流入", flow.total_net_inflow)
```

## 返回字段

| 字段 | 含义 |
| --- | --- |
| `super_in` / `large_in` / `medium_in` / `small_in` | 四档流入金额 |
| `super_out` / `large_out` / `medium_out` / `small_out` | 四档流出金额 |
| `main_net_inflow` | 主力净流入（超大单 + 大单） |
| `total_net_inflow` | 全单净流入 |

## 使用说明

| 项目 | 说明 |
| --- | --- |
| 逐笔来源 | 复用 `client.trades.all_today(code)`，自动翻页到空页为止 |
| 方向 | 仅统计 `buy` / `sell` 方向的成交，`neutral` 与集合竞价快照不参与 |
| 历史资金流 | 需要历史日线资金流时用 [`client.money_flow.daily(code)`](0x0ffc-资金流向日数据接口.md) |
| 缓存 | 不缓存；每次调用都请求主站 |
